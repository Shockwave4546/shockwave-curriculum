# Algorithms with Selection and Repetition — Worked Example

**Outline ref:** 5.3 — Algorithms with Selection and Repetition (CSA 2.1)
**Pairs with:** [`lessons/ch05-control-structures/5.3-algorithms-with-selection-and-repetition.md`](../../lessons/ch05-control-structures/5.3-algorithms-with-selection-and-repetition.md)
**Status:** new — authored worked example (fully solved, walked step by step — not a problem to attempt)

## Problem

Before a match, the pit crew checks four subsystems — `Drivetrain`, `Intake`, `Shooter`, `Climber` — each already marked as passed or not in a matching boolean array. Print a two-line report for each subsystem: its name, then `PASS` or `FAIL`.

## Step 1: Plan It as Pseudocode First

Before writing real Java, sketch the shape of the algorithm in plain English — this is exactly the habit from Lesson 5.3, applied here:

```
For each subsystem:
    Print its name
    If its check passed, print PASS
    Otherwise, print FAIL
```

Already visible in that pseudocode are all three building blocks: **repetition** (the "for each"), **sequence** (name printed, then the result), and **selection** (the PASS/FAIL branch).

## Step 2: Set Up the Data

Two arrays, kept in matching order — the name at index `i` belongs with the check result at index `i`:

```java
String[] subsystems = {"Drivetrain", "Intake", "Shooter", "Climber"};
boolean[] checkPassed = {true, true, false, true};
```

## Step 3: Add the Repetition

A `for` loop visits every index once, from `0` up to (not including) the array's length:

```java
for (int i = 0; i < subsystems.length; i++)
{

}
```

## Step 4: Add the Sequence and Selection

Each pass through the loop runs two statements in order (sequence) — a plain print, then an `if`/`else` (selection):

```java
for (int i = 0; i < subsystems.length; i++)
{
    System.out.println(subsystems[i]);

    if (checkPassed[i])
    {
        System.out.println("PASS");
    }
    else
    {
        System.out.println("FAIL");
    }
}
```

`checkPassed[i]` is already a `boolean`, so it can sit directly inside the `if`'s parentheses — no comparison needed.

## Step 5: Trace the Output

| `i` | name | `checkPassed[i]` | printed |
|---|---|---|---|
| 0 | Drivetrain | true | `Drivetrain` / `PASS` |
| 1 | Intake | true | `Intake` / `PASS` |
| 2 | Shooter | false | `Shooter` / `FAIL` |
| 3 | Climber | true | `Climber` / `PASS` |

Four iterations, two printed lines each — eight lines of output total, entirely predictable from reading the pseudocode.

## Recap

- Every algorithm is built from sequence, selection, and repetition — nothing else is needed.
- Pseudocode (informal step-by-step notes) is a real planning tool, not busywork — use it before writing real code for anything with multiple branches or a loop.
