# Implementing Selection and Iteration Algorithms — Worked Example

**Outline ref:** 5.9 — Implementing Selection and Iteration Algorithms (CSA 2.9)
**Pairs with:** [`lessons/ch05-control-structures/5.9-implementing-selection-and-iteration-algorithms.md`](../../lessons/ch05-control-structures/5.9-implementing-selection-and-iteration-algorithms.md)
**Status:** new — authored worked example (fully solved, walked step by step — not a problem to attempt)

## Problem

Given the points scored in each of 6 practice runs, compute and print: the average score, the highest score, and how many runs scored `0` points. Then simulate a 15% chance of a "bonus token" spawning during one more practice run.

## Step 1: Start From the Data

```java
int[] practiceScores = {12, 0, 20, 15, 0, 18};
```

## Step 2: The Accumulator Pattern — Average

Initialize a running total before the loop, add to it inside the loop, then use the result after the loop ends:

```java
int sum = 0;
for (int score : practiceScores)
{
    sum += score;
}
double average = sum / (double) practiceScores.length;
System.out.println("Average: " + average);
```

`sum` has to start at `0` — the identity value for addition — so the first real score adds in correctly. Casting to `(double)` before dividing avoids integer division truncating the result.

## Step 3: Min/Max Pattern — Highest Score

Pair an accumulator with an `if` inside the loop, comparing each new value against the best one seen so far:

```java
int max = Integer.MIN_VALUE;
for (int score : practiceScores)
{
    if (score > max)
    {
        max = score;
    }
}
System.out.println("Highest: " + max);
```

`max` starts at the smallest possible `int` specifically so that the very first real score is guaranteed to be greater than it, replacing it immediately. Starting `max` at `0` instead would silently break this the moment every score happened to be negative.

## Step 4: Frequency Counting — Runs Scoring Zero

A counter incremented inside a conditional, once per matching iteration:

```java
int zeroCount = 0;
for (int score : practiceScores)
{
    if (score == 0)
    {
        zeroCount++;
    }
}
System.out.println("Scoreless runs: " + zeroCount);
```

The increment (`zeroCount++`) has to live *inside* the `if`, not the loop body unconditionally — otherwise it would count every run, not just the matching ones.

## Step 5: Simulating Probability

`Math.random()` returns a value from `0.0` up to (not including) `1.0`, spread evenly — so `Math.random() < 0.15` is true roughly 15% of the time:

```java
if (Math.random() < 0.15)
{
    System.out.println("Bonus token spawned!");
}
```

Running this line many times would show a bonus token roughly 15 times out of every 100 — a real way to simulate a randomly-occurring event for testing.

## Recap

- The accumulator pattern: initialize before the loop, update inside it, use the result after.
- Min/max tracking pairs an accumulator with an `if` inside the loop, comparing each new value against the best one seen so far.
- Frequency counting increments a counter inside a conditional, once per matching iteration.
- `Math.random() < p` simulates an event with probability `p`.
