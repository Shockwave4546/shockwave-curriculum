# Nested Iteration — Worked Example

**Outline ref:** 5.10 — Nested Iteration (CSA 2.11)
**Pairs with:** [`lessons/ch05-control-structures/5.10-nested-iteration.md`](../../lessons/ch05-control-structures/5.10-nested-iteration.md)
**Status:** new — authored worked example (fully solved, walked step by step — not a problem to attempt)

## Problem

The elevator has 4 limit switches wired for redundancy. As a wiring sanity check, compare every switch against every other switch (including itself) and print `CONFLICT` for any pair that's triggered at the same time — that would mean the elevator is at two contradictory positions at once.

## Step 1: Start From the Data

```java
boolean[] limitSwitch = {true, false, false, true};
```

## Step 2: Set Up the Outer Loop

The outer loop picks the first switch in each pair:

```java
for (int i = 0; i < limitSwitch.length; i++)
{

}
```

## Step 3: Nest the Inner Loop

For every single value of `i`, the inner loop needs to run all the way through every value of `j` — that's what "nested" means. The inner loop uses a different variable name, `j`, since `for (int i ...)` nested inside another `for (int i ...)` in the same scope won't compile:

```java
for (int i = 0; i < limitSwitch.length; i++)
{
    for (int j = 0; j < limitSwitch.length; j++)
    {

    }
}
```

## Step 4: Add the Check

Both switches being triggered at once (`&&`) is a conflict:

```java
for (int i = 0; i < limitSwitch.length; i++)
{
    for (int j = 0; j < limitSwitch.length; j++)
    {
        if (limitSwitch[i] && limitSwitch[j])
        {
            System.out.println("CONFLICT: switch " + i + " and switch " + j);
        }
    }
}
```

## Step 5: Trace a Few Passes

With `limitSwitch = {true, false, false, true}`, when the outer loop is at `i = 0` (`limitSwitch[0]` is `true`), the inner loop restarts from `j = 0` and runs completely through `j = 0, 1, 2, 3` before the outer loop ever advances to `i = 1`:

| `i` | `j` | `limitSwitch[i] && limitSwitch[j]` | printed |
|---|---|---|---|
| 0 | 0 | true | `CONFLICT: switch 0 and switch 0` |
| 0 | 1 | false | — |
| 0 | 2 | false | — |
| 0 | 3 | true | `CONFLICT: switch 0 and switch 3` |
| 1 | 0 | false | — |
| 1 | 1 | false | — |
| … | … | … | … |

The inner loop's `j` variable is freshly re-initialized to `0` at the start of every outer pass — it doesn't remember where it left off from the previous `i`.

## Step 6: Why It's Shaped This Way

Sixteen total comparisons (4 outer × 4 inner) come out of just two loops — this pairwise-checking shape is the same one that comes up scanning a 2D vision frame or generating a table of test cases: anything where every item needs to be checked against every other item.

## Recap

- A loop nested inside another runs completely, every single time the outer loop takes one step.
- Nested loops are the standard shape for anything grid-shaped — rows and columns, pairs of items, tables of test cases.
- Use distinct loop variable names for nested loops (`row`/`col`, not `i`/`i`).
