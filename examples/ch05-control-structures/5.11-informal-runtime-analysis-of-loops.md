# Informal Runtime Analysis of Loops — Worked Example

## Problem

Predict, by hand, how many times each of two loops from the pit's LED-strip diagnostic routine will run — a single loop counting practice matches, and a nested loop scanning every LED in the strip — then confirm both with a counter.

## Step 1: The Single-Loop Case

```java
for (int match = 2; match <= 9; match++)
{
    runDiagnostic(match);
}
```

The formula: `largest value the loop variable reaches − smallest value + 1`. This loop uses a `<=` bound, so the largest value it reaches is the limit itself, `9`; the smallest is `2`:

```
9 - 2 + 1 = 8
```

Eight iterations, visiting `match = 2, 3, 4, 5, 6, 7, 8, 9` — eight values, matching the formula exactly.

## Step 2: Confirm It With a Counter

```java
int matchCount = 0;
for (int match = 2; match <= 9; match++)
{
    matchCount++;
}
System.out.println(matchCount);  // 8
```

## Step 3: The Nested-Loop Case

The LED strip has 3 segments, each with 20 LEDs, scanned with a loop inside a loop:

```java
for (int segment = 0; segment < 3; segment++)
{
    for (int led = 0; led < 20; led++)
    {
        checkLed(segment, led);
    }
}
```

The outer loop's bound is `< 3` starting at `0`, so it runs `3 - 0 = 3` times (a `<` bound's largest reachable value is one less than the limit, here making the count simply the limit itself since it starts at `0`). The inner loop, by the same reasoning, runs `20` times for every single outer pass. A nested loop's total is outer count × inner count, not outer + inner:

```
3 × 20 = 60
```

## Step 4: Confirm the Nested Count

```java
int ledChecks = 0;
for (int segment = 0; segment < 3; segment++)
{
    for (int led = 0; led < 20; led++)
    {
        ledChecks++;
    }
}
System.out.println(ledChecks);  // 60
```

## Step 5: Why Bother Counting by Hand First

If `ledChecks` had printed something other than `60` — say the inner bound had been mistyped as `<= 20` — counting by hand first (`3 × 21 = 63`, not `60`) would immediately flag the mismatch and point straight at the inner loop's bound, without needing to add print statements inside the loop and re-run the whole program to hunt for the bug.

## Recap

- A loop's iteration count is `largest reachable value − smallest value + 1`.
- Nested loops multiply: total iterations = outer count × inner count.
- Counting iterations by hand is a fast way to catch an off-by-one bug before it turns into a mysterious runtime problem.
