# String Algorithms — Worked Example

**Outline ref:** 6.2 — String Algorithms (CSA 2.10)
**Pairs with:** [`lessons/ch06-strings/6.2-string-algorithms.md`](../../lessons/ch06-strings/6.2-string-algorithms.md)
**Status:** new — authored worked example (fully solved, walked step by step — not a problem to attempt)

## Problem

A driver types the name of an autonomous routine into the dashboard before a match, e.g. `"Left  Start Cone"` — they double-tapped the spacebar by accident. Before the routine name can be written to the match log as a filename-safe tag, count how many spaces it contains, replace every space with an underscore, and build a reversed copy of the cleaned name for a scrolling ticker display.

## Step 1: Plan It First

1. Scan every character and count the spaces — a known number of characters to check, so a `for` loop fits.
2. Replace spaces with underscores one at a time until none remain — an unknown number of matches, so a `while` loop paired with `indexOf` fits.
3. Build a reversed copy of the cleaned name by concatenating onto a new string, one character at a time.

## Step 2: Set Up the Class and `main`

```java
public class RoutineNameCleaner
{
    public static void main(String[] args)
    {
        String rawName = "Left  Start Cone";
    }
}
```

## Step 3: Count the Spaces

Visiting every character exactly once, in order, is exactly what a `for` loop is for:

```java
int spaceCount = 0;
for (int i = 0; i < rawName.length(); i++)
{
    if (rawName.substring(i, i + 1).equals(" "))
    {
        spaceCount++;
    }
}
```

`substring(i, i + 1)` pulls out the single character at index `i`. The loop starts at 0 and stops before `length()`, so every index from the first character to the last gets checked exactly once.

## Step 4: Replace Every Space with an Underscore

There's no way to know in advance how many spaces the driver typed, so a `while` loop keeps going until `indexOf` reports there are none left:

```java
String cleanedName = rawName;
while (cleanedName.indexOf(" ") >= 0)
{
    int i = cleanedName.indexOf(" ");
    String firstPart = cleanedName.substring(0, i);
    String lastPart = cleanedName.substring(i + 1);
    cleanedName = firstPart + "_" + lastPart;
}
```

Each pass reassigns `cleanedName`, so the next `indexOf(" ")` search runs against the already-partially-cleaned string and finds the *next* remaining space. Because `"Left  Start Cone"` has two spaces back to back plus one more, this loop runs three times.

## Step 5: Build the Reversed Name

Building a new string means starting empty and concatenating inside a loop — strings can't be edited in place:

```java
String reversedName = "";
for (int i = 0; i < cleanedName.length(); i++)
{
    String letter = cleanedName.substring(i, i + 1);
    reversedName = letter + reversedName;
}
```

Prepending each letter (`letter + reversedName`, not `reversedName + letter`) is what builds the string backwards.

## Step 6: Print and Verify

```java
System.out.println("Spaces found: " + spaceCount);
System.out.println("Cleaned name: " + cleanedName);
System.out.println("Reversed name: " + reversedName);
```

Output:

```
Spaces found: 3
Cleaned name: Left__Start_Cone
Reversed name: enoC_tratS__tfeL
```

## What Starting at Index 1 Would Look Like

If Step 3's loop had started at `i = 1` instead of `i = 0`, the first character would never be checked — a space in the very first position would be silently missed. The first character of any string is always at index 0.

## What `<=` Would Look Like

If Step 3 or Step 5's condition had been written `i <= rawName.length()` instead of `i < rawName.length()`, the last pass would call `substring(length(), length() + 1)` — one index past the end — and throw an `IndexOutOfBoundsException` instead of finishing.

## Recap

- A `for` loop fit counting the spaces, since every character needed exactly one check.
- A `while` loop paired with `indexOf` fit replacing the spaces, since the number of matches wasn't known ahead of time — each pass reassigned `cleanedName` and searched again against the updated value.
- Building the reversed name started from an empty string and concatenated one character at a time inside a `for` loop, since strings can't be modified in place.
