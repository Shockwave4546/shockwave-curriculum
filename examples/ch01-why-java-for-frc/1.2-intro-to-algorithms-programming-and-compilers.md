# Intro to Algorithms, Programming & Compilers — Worked Example

## Problem

Print your team's name, then your team's number, each on its own line.

## Step 1: Plan It First

Before touching code, write the steps in plain English — this is the algorithm:

1. Print the team name.
2. Print the team number.

Two steps, run in order — sequencing.

## Step 2: Set Up the Class and `main`

Every Java program needs a `class`, and every class we run needs a `main` method. Nothing prints yet — this is just the skeleton every program starts from:

```java
public class TeamInfo
{
    public static void main(String[] args)
    {

    }
}
```

The file this lives in must be named `TeamInfo.java`, matching `public class TeamInfo`. Notice the opening brace `{` has no semicolon before it — braces open and close blocks, they aren't statements.

## Step 3: Fill In the Statements

Each planned step becomes one statement, and every statement ends with `;`:

```java
public class TeamInfo
{
    public static void main(String[] args)
    {
        System.out.println("Shockwave");
        System.out.println("1622");
    }
}
```

`System.out.println(...)` is how a Java program prints a line of text. Two calls, run top to bottom — this is exactly the two-step plan from Step 1.

## Step 4: Check the Naming

- `TeamInfo` is a class name → **PascalCase**, every word capitalized.
- `main` is a method name → **lowerCamelCase**, starts lowercase.
- `public`, `class`, `static`, `void` are **keywords** → always lowercase, fixed meaning, never chosen by you.

`System` is capitalized because it's a class; `println` is lowercase because it's a method. Same rule as everywhere else in Java.

## Step 5: Add a Comment

A comment explains the code to a human — the compiler skips it entirely. Here's the finished program with one added:

```java
public class TeamInfo
{
    public static void main(String[] args)
    {
        System.out.println("Shockwave");   // team name
        System.out.println("1622");        // team number
    }
}
```

## What Compiling Does Here

Running this through the compiler translates it into something the computer can execute, and it prints:

```
Shockwave
1622
```

## What a Syntax Error Would Look Like

If Step 3 had been typed without the semicolon —

```java
System.out.println("Shockwave")
```

— the compiler would stop before the program ever runs and point at that line. That's a **syntax error**: caught at compile time, before execution, not a run-time error.

## Recap

- Plan in plain English first (algorithm), then translate each step into one statement.
- Every statement ends in `;`; lines that open a block (`{`) don't.
- Class names are PascalCase, method names are lowerCamelCase, keywords are always lowercase.
- Comments (`//`) are for humans — the compiler ignores them.
- A missing `;` is a syntax error, caught before the program runs.
