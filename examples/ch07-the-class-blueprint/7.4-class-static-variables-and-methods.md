# Class (static) Variables & Methods — Worked Example

**Outline ref:** 7.4 — Class (static) Variables and Methods (CSA 3.7)
**Pairs with:** [`lessons/ch07-the-class-blueprint/7.4-class-static-variables-and-methods.md`](../../lessons/ch07-the-class-blueprint/7.4-class-static-variables-and-methods.md)
**Status:** new — authored worked example (fully solved, walked step by step — not a problem to attempt)

## Problem

Write a `Match` class that keeps a running count of how many matches have been played across the whole season, and tracks the single highest score seen in any match — both shared across every `Match` object, not per-object.

## Step 1: A Static Variable for the Running Count

`static` means one shared copy belonging to the class itself, not to any one object:

```java
public class Match
{
    public static int matchesPlayed = 0; // one shared copy for ALL Match objects
}
```

## Step 2: Increment It in the Constructor

Every time a `Match` object is constructed, one more match has been played:

```java
public class Match
{
    public static int matchesPlayed = 0;
    private double score;

    public Match(double finalScore)
    {
        score = finalScore;
        matchesPlayed++; // updates the ONE shared counter
    }
}
```

## Step 3: A Static Variable Tracking the Running Maximum

```java
public class Match
{
    public static int matchesPlayed = 0;
    public static double highestScore = 0.0;
    private double score;

    public Match(double finalScore)
    {
        score = finalScore;
        matchesPlayed++;

        if (finalScore > highestScore)
        {
            highestScore = finalScore; // updates the ONE shared value
        }
    }
}
```

## Step 4: Why a Static Method Can't Just Read `score`

Suppose we want a static method that prints a match's score. This does **not** compile:

```java
public static void showScore()
{
    System.out.println(score); // compile error! no object to read this from
}
```

`score` is an instance variable — it only exists once a specific `Match` object exists. A `static` method runs without any particular object in hand, so it has no `score` to read. The fix is to pass an actual `Match` in as a parameter:

```java
public static void printScore(Match m)
{
    System.out.println(m.score); // fine — reading one specific object's data
}
```

## Step 5: A Constant With `final`

The length of a match itself doesn't change match to match, so it's a true constant, not a running value:

```java
public static final double MATCH_TIME_SECONDS = 150.0; // 15s auto + 135s teleop
```

## Step 6: Put It Together

```java
public class Match
{
    public static int matchesPlayed = 0;
    public static double highestScore = 0.0;
    public static final double MATCH_TIME_SECONDS = 150.0;

    private double score;

    public Match(double finalScore)
    {
        score = finalScore;
        matchesPlayed++;

        if (finalScore > highestScore)
        {
            highestScore = finalScore;
        }
    }

    public static void printScore(Match m)
    {
        System.out.println(m.score);
    }
}
```

## Step 7: Try It

```java
Match first = new Match(45.0);
Match second = new Match(78.0);

System.out.println(Match.matchesPlayed); // 2
System.out.println(Match.highestScore);  // 78.0
```

```
2
78.0
```

Both `first` and `second` see the same `matchesPlayed` and `highestScore` — there's only ever one copy, shared across every `Match` ever built. Notice `matchesPlayed` and `highestScore` are read through the class name, `Match.matchesPlayed`, not through `first` or `second` — they don't belong to either object.

## Recap

- `static` members belong to the class itself — `matchesPlayed` and `highestScore` are one shared copy, no matter how many `Match` objects exist.
- Static code can't access instance variables or instance methods directly — `printScore` needed an actual `Match` object passed in to reach `score`.
- A static variable's value is shared across every object — that's what let `matchesPlayed` and `highestScore` track totals across every `Match` ever constructed.
- `final` marks a variable as an unchangeable constant, conventionally named in ALL_CAPS — `MATCH_TIME_SECONDS` here.
