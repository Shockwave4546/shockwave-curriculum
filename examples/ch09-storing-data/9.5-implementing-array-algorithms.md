# Implementing Array Algorithms — Worked Example

## Problem

Given this weekend's practice-match scores, find the average, find the highest score, check whether the team ever scored exactly 100, count how many matches scored 40 or above, check for two matches in a row with the exact same score, and produce a reversed copy for a "most recent first" display.

## Step 1: Plan It First

Six small tasks, each one of the standard array-algorithm patterns:

1. Average — accumulator.
2. Highest score — running max.
3. Ever scored exactly 100 — search.
4. Count of matches at or above 40 — property count.
5. Two matches in a row with the same score — adjacent duplicates.
6. Most-recent-first order — reverse in place.

```java
double[] matchScores = {38.0, 45.5, 45.5, 52.0, 40.0};
```

## Step 2: Average (Accumulator)

```java
double sum = 0;
for (double score : matchScores)
{
    sum += score;
}
double average = sum / matchScores.length;
System.out.println(average); // 44.2
```

## Step 3: Highest Score (Running Max)

Seed `max` with the first element, not `0` — a score could theoretically be recorded as a negative correction, and `0` isn't guaranteed to be a real lower bound:

```java
double max = matchScores[0];
for (double score : matchScores)
{
    if (score > max)
    {
        max = score;
    }
}
System.out.println(max); // 52.0
```

## Step 4: Ever Scored Exactly 100 (Search)

A match should return the instant it's found — but "not found" can only be concluded after every element has been checked:

```java
public static boolean everScored(double[] scores, double target)
{
    for (double score : scores)
    {
        if (score == target)
        {
            return true; // fine to return early on a MATCH
        }
    }
    return false; // only after checking every element
}
```

```java
System.out.println(everScored(matchScores, 100.0)); // false
```

## Step 5: Count of Matches at or Above 40 (Property Count)

```java
int qualifyingCount = 0;
for (double score : matchScores)
{
    if (score >= 40.0)
    {
        qualifyingCount++;
    }
}
System.out.println(qualifyingCount); // 4
```

## Step 6: Two Matches in a Row With the Same Score (Adjacent Duplicates)

Only neighboring elements matter here, so a single loop comparing `matchScores[i]` to `matchScores[i + 1]` is enough — bounded by `length - 1` so it never reads one past the end:

```java
public static boolean hasBackToBackTie(double[] scores)
{
    for (int i = 0; i < scores.length - 1; i++)
    {
        if (scores[i] == scores[i + 1])
        {
            return true;
        }
    }
    return false;
}
```

```java
System.out.println(hasBackToBackTie(matchScores)); // true — matches 2 and 3 both scored 45.5
```

## Step 7: Most-Recent-First Order (Reverse in Place)

Swap from both ends toward the middle using a temporary variable:

```java
int start = 0, end = matchScores.length - 1;
while (start < end)
{
    double temp = matchScores[start];
    matchScores[start] = matchScores[end];
    matchScores[end] = temp;
    start++;
    end--;
}
// matchScores is now: 40.0, 52.0, 45.5, 45.5, 38.0
```

## Recap

- Sum/average, min/max, search, and property-counting are all the same basic shape: a loop plus a little state (an accumulator, a running best, a counter, or an early return).
- Seeding `max` with the first element (not `0`) avoids a wrong starting point if real values could be at or below zero.
- A search for "not found" must check every element before concluding absence; a search for a match can return the instant it's found.
- Adjacent-duplicate checks are a single loop, bounded by `length - 1` so it never reads one past the end.
- Reversing in place swaps from both ends toward the middle using a temporary variable.
