# ArrayList Traversals — Worked Example

## Problem

The pit crew keeps a running to-do list of tasks. Each finished task is marked with a `"DONE: "` prefix — write code that removes every finished task from the list, and print each remaining crew member's name from a separate roster list by chaining through its objects.

## Step 1: Plan It First

1. Look at the task list with a read-only pass.
2. Try removing finished tasks with a for-each loop, and see what goes wrong.
3. Remove finished tasks correctly instead.
4. Print each crew member's name by chaining through a list of objects.

```java
ArrayList<String> pitTasks = new ArrayList<String>();
pitTasks.add("DONE: Check drive belt tension");
pitTasks.add("Replace bumper pool noodle");
pitTasks.add("DONE: Charge spare battery");
pitTasks.add("Re-tape wiring harness");
```

## Step 2: Read-Only Pass — For-Each Works Fine Here

```java
for (String task : pitTasks)
{
    System.out.println(task);
}
```

For-each, indexed `for`, and `while` all work on an `ArrayList` — just with `get(i)` instead of `[i]`, and `.size()` instead of `.length`. A pass that only reads is safe with any of them.

## Step 3: What Goes Wrong With a Naive For-Each Removal

```java
for (String task : pitTasks)
{
    if (task.startsWith("DONE: "))
    {
        pitTasks.remove(task); // throws ConcurrentModificationException
    }
}
```

Adding or removing elements from an `ArrayList` while a for-each loop is traversing it throws `ConcurrentModificationException`. Removing while looping needs an indexed `for` or `while` loop instead.

## Step 4: Removing While Looping — The Careful Way

Removing an element shifts every later element down by one index. Incrementing the loop index *unconditionally* after a removal would skip the element that just shifted into the spot just checked:

```java
int i = 0;
while (i < pitTasks.size())
{
    if (pitTasks.get(i).startsWith("DONE: "))
    {
        pitTasks.remove(i); // don't increment i here — the next task just shifted into index i
    }
    else
    {
        i++; // only advance when nothing was removed this iteration
    }
}
```

```java
System.out.println(pitTasks);
// [Replace bumper pool noodle, Re-tape wiring harness]
```

## Step 5: Chaining Through a List of Objects

A separate roster tracks crew members as objects rather than plain text:

```java
public class CrewMember
{
    private String name;

    public CrewMember(String name)
    {
        this.name = name;
    }

    public String getName()
    {
        return name;
    }
}
```

```java
ArrayList<CrewMember> roster = new ArrayList<CrewMember>();
roster.add(new CrewMember("Alex"));
roster.add(new CrewMember("Priya"));

for (int i = 0; i < roster.size(); i++)
{
    System.out.println(roster.get(i).getName()); // chain: get the object, then call a method on it
}
```

`roster.get(i)` returns a `CrewMember` object, and `.getName()` is called directly on that result — a chain, rather than storing the object in its own variable first.

## Recap

- `ArrayList` supports the same loop shapes as arrays, using `get(i)`/`.size()` instead of `[i]`/`.length`.
- Never add or remove elements from an `ArrayList` while traversing it with a for-each loop — it throws `ConcurrentModificationException`.
- When removing elements in an indexed/while loop, only advance the index on iterations where nothing was removed.
