# Optional: HashMap (Dictionary) Data Structure — Worked Example

## Problem

Store a one-line scouting note for each opposing team you've scouted so far, keyed by team number, then look one up right before a match and print every note you have collected.

## Step 1: Plan It First

1. Store each team's scouting note, looked up by team number.
2. Look up one team's note before facing them.
3. Handle looking up a team that was never scouted.
4. Print every note collected so far.

## Step 2: Why Not an Array or ArrayList Here

Arrays and `ArrayList` are naturally indexed by position (0, 1, 2...). Here, the natural "index" is a team number — not a position — so a `HashMap` fits: it maps each **key** (team number) to a **value** (the note).

```java
import java.util.HashMap;

HashMap<Integer, String> scoutingNotes = new HashMap<Integer, String>();
```

## Step 3: Add Notes

`put(key, value)` adds a pair:

```java
scoutingNotes.put(1622, "Fast auto, weak endgame");
scoutingNotes.put(254, "Consistent 3-piece, strong climb");
scoutingNotes.put(4414, "New drivetrain this year, watch for reliability issues");
```

## Step 4: Look Up a Team Before a Match

`get(key)` retrieves the value for a key:

```java
String note = scoutingNotes.get(254);
System.out.println(note); // Consistent 3-piece, strong climb
```

## Step 5: Looking Up a Team Never Scouted

Calling `get()` with a key that was never `put()` doesn't throw an error — it returns `null`:

```java
String unknownNote = scoutingNotes.get(9999);
System.out.println(unknownNote); // null
```

Code that looks up a team it might not have scouted yet should check for `null` before assuming there's a real note.

## Step 6: Print Every Note Collected

`keySet()` gives every key, which can then be used with `get()` to reach each value:

```java
for (int teamNumber : scoutingNotes.keySet())
{
    String scoutedNote = scoutingNotes.get(teamNumber);
    System.out.println(teamNumber + ": " + scoutedNote);
}
```

This is guaranteed to print every team scouted so far — but not necessarily in the order they were `put()` in, since `HashMap` doesn't remember insertion order the way `ArrayList` does.

## Recap

- A `HashMap<KeyType, ValueType>` stores unique keys mapped to values — here, team numbers mapped to scouting notes.
- `put(key, value)` adds or replaces a pair; `get(key)` retrieves the value.
- Reach for a `HashMap` when you naturally look things up by name/ID (a team number) rather than by position.
- `get()` on a key that was never `put()` returns `null` instead of throwing an error.
- `keySet()` gives every key, for looping through all pairs with `get()` — but in no guaranteed order.
