# Array Traversals — Worked Example

## Problem

Given this weekend's 5 practice-match scores, print each one next to its match number, print just the scores on their own, then write a method that zeroes out any negative score in the array (a typo during data entry) — and make sure that change is actually visible back where the array came from.

## Step 1: Plan It First

1. Print each score with its match number (need the index).
2. Print just the scores, no numbers needed (don't need the index).
3. Zero out any negative scores, and make sure the fix is visible outside the method.

## Step 2: Print With Match Numbers — Indexed Loop

Match numbers usually start at 1, so the printed label is `i + 1` while the array index itself stays 0-based:

```java
double[] matchScores = {38.0, 45.5, -12.0, 52.0, 40.0}; // -12.0 is a data-entry mistake

for (int i = 0; i < matchScores.length; i++)
{
    System.out.println("Match " + (i + 1) + ": " + matchScores[i]);
}
```

The loop bound is written against `matchScores.length`, not a hardcoded `5` — the same code keeps working if a 6th match gets added.

## Step 3: Print Just the Scores — Enhanced For-Each

No index is needed here, so the simpler for-each form fits:

```java
for (double score : matchScores)
{
    System.out.println(score);
}
```

It always starts at index 0 and runs through every element in order — genuinely equivalent to the indexed loop in Step 2, just more concise.

## Step 4: Zero Out Negative Scores — Why For-Each Won't Work

A tempting first attempt:

```java
for (double score : matchScores)
{
    if (score < 0)
    {
        score = 0.0; // compiles, runs, and changes nothing
    }
}
```

`score` inside a for-each loop is a local copy of each element — reassigning it never touches the real array. Fixing an element in place needs an indexed loop instead.

## Step 5: Zero Out Negative Scores — Indexed Loop That Actually Works

```java
public static void zeroOutNegatives(double[] scores)
{
    for (int i = 0; i < scores.length; i++)
    {
        if (scores[i] < 0)
        {
            scores[i] = 0.0;
        }
    }
}
```

```java
zeroOutNegatives(matchScores);
System.out.println(matchScores[2]); // 0.0 — the caller's array really did change
```

## Step 6: Why the Caller's Array Actually Changed

`matchScores` is an object, so passing it into `zeroOutNegatives` passes the reference — `scores` inside the method and `matchScores` outside it refer to the same array in memory. Changes made through `scores[i] = ...` are visible back in the caller once the method returns, the same as any other mutable object.

## Recap

- Traversing an array means looping through it, index by index, with the loop bound written against `.length`.
- The for-each loop (`for (type v : array)`) is simpler when you don't need the index and won't modify elements.
- For-each cannot modify primitive array elements — reassigning the loop variable only changes a local copy.
- Arrays are objects — a method that changes array elements through an indexed loop changes the caller's real array too.
