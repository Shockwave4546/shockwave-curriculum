# Array Creation and Access — Worked Example

## Problem

The drivetrain has 4 motors. Store each motor's CAN bus ID and its mount position label ("Front-Left", "Front-Right", "Back-Left", "Back-Right"), then build an array of actual motor objects from those IDs.

## Step 1: Plan It First

1. Store the 4 CAN bus IDs.
2. Store the 4 position labels, kept in the same order as the IDs.
3. Build an array of `Motor` objects, one per CAN bus ID.
4. Show what happens if code asks for a 5th motor that doesn't exist.

## Step 2: Create the ID Array

An initializer list creates the array and fills it in one step — no separate `new` needed:

```java
int[] canBusIds = {1, 2, 3, 4};
```

`canBusIds` now refers to a fixed-size array object holding exactly 4 `int` values.

## Step 3: Read and Write by Index

Indices start at 0, and the last valid index is `canBusIds.length - 1`:

```java
System.out.println(canBusIds.length);   // 4
System.out.println(canBusIds[0]);       // 1 — the Front-Left motor's ID

canBusIds[3] = 9;                       // the Back-Right motor got re-wired to CAN ID 9
System.out.println(canBusIds[3]);       // 9
```

`length` is a field, not a method — no parentheses, unlike `String.length()`.

## Step 4: Add a Parallel Array

A second array, kept in the same order, lets index `i` in `positions` describe index `i` in `canBusIds`:

```java
String[] positions = {"Front-Left", "Front-Right", "Back-Left", "Back-Right"};

System.out.println(positions[0] + " is CAN ID " + canBusIds[0]); // Front-Left is CAN ID 1
```

`canBusIds` and `positions` are **parallel arrays** — the same index always refers to the same motor across both.

## Step 5: Build an Array of Motor Objects

An array can hold objects too, but each element still needs to be constructed individually — `new Motor[4]` alone would give 4 `null` slots, not 4 ready-to-use motors:

```java
public class Motor
{
    private int canBusId;

    public Motor(int canBusId)
    {
        this.canBusId = canBusId;
    }

    public int getCanBusId()
    {
        return canBusId;
    }
}
```

```java
Motor[] motors = new Motor[4]; // 4 null slots so far
motors[0] = new Motor(canBusIds[0]);
motors[1] = new Motor(canBusIds[1]);
motors[2] = new Motor(canBusIds[2]);
motors[3] = new Motor(canBusIds[3]);

System.out.println(motors[0].getCanBusId()); // 1
```

Each `motors[i]` had to be built with its own `new Motor(...)` call — the array only reserves the slots.

## Step 6: What Asking for a 5th Motor Does

There is no `motors[4]` — only indices 0 through 3 exist:

```java
System.out.println(motors[4]); // throws ArrayIndexOutOfBoundsException
```

This fails at run time, not at compile time — the array doesn't know how many elements "should" exist, only how many it was actually given (4, since `length` is 4 and the last valid index is `length - 1`, which is 3).

## Recap

- An array is a fixed-size, same-type collection, accessed by a 0-based index.
- An initializer list creates and fills an array in one step; `length` is a field, and the last valid index is `length - 1`.
- Parallel arrays (`canBusIds` and `positions`) keep related data in sync by index.
- An array of objects still requires constructing each element individually — `new Motor[4]` gives 4 `null` slots, not 4 motors.
- Accessing an index outside `0` to `length - 1` throws `ArrayIndexOutOfBoundsException` at run time.
