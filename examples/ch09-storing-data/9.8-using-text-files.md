# Using Text Files — Worked Example

## Problem

Read a CSV file of this weekend's practice-match results — one row per match, with a header row — into a list of `MatchResult` objects, then print each one.

`practice_scores.csv`:
```
matchNumber,score,opponent
1,38.0,IronClad
2,45.5,Voltage Vipers
3,52.0,Circuit Breakers
```

## Step 1: Plan It First

1. Open the file.
2. Skip the header row.
3. Read each remaining row and split it into fields.
4. Build one `MatchResult` object per row.
5. Close the file, then print the results.

## Step 2: Define `MatchResult`

Rather than juggling raw `String[]` rows everywhere, one object per record keeps the three related fields together:

```java
public class MatchResult
{
    private int matchNumber;
    private double score;
    private String opponent;

    public MatchResult(int matchNumber, double score, String opponent)
    {
        this.matchNumber = matchNumber;
        this.score = score;
        this.opponent = opponent;
    }

    public String toString()
    {
        return "Match " + matchNumber + ": " + score + " vs " + opponent;
    }
}
```

## Step 3: Open the File

`File` represents the file itself; `Scanner` reads from it. Opening a file can fail, so the method needs `throws IOException`:

```java
import java.io.*;
import java.util.*;

public static void main(String[] args) throws IOException
{
    File scoresFile = new File("practice_scores.csv");
    Scanner scan = new Scanner(scoresFile);

    // ...
}
```

## Step 4: Skip the Header Row

The first line is column names, not data — reading it as a row would crash when `Double.parseDouble` hit the text `"score"`:

```java
scan.nextLine(); // discards "matchNumber,score,opponent"
```

## Step 5: Read Each Remaining Row Into a `MatchResult`

`hasNext()` combined with a `while` loop reads until the file ends; each line is split on commas into fields:

```java
ArrayList<MatchResult> results = new ArrayList<MatchResult>();

while (scan.hasNext())
{
    String line = scan.nextLine();
    String[] fields = line.split(",");

    int matchNumber = Integer.parseInt(fields[0]);
    double score = Double.parseDouble(fields[1]);
    String opponent = fields[2];

    results.add(new MatchResult(matchNumber, score, opponent));
}
```

`ArrayList` is used here rather than an array because the number of matches isn't known in advance — it's however many rows the file happens to have.

## Step 6: Close the File

```java
scan.close();
```

Always close a `Scanner` once done reading — a small leak that adds up in a program that opens many files.

## Step 7: Print the Results

```java
for (MatchResult result : results)
{
    System.out.println(result);
}
```

```
Match 1: 38.0 vs IronClad
Match 2: 45.5 vs Voltage Vipers
Match 3: 52.0 vs Circuit Breakers
```

## Recap

- `File` represents the file; `Scanner` reads from it — both can throw exceptions if the file can't be opened, which Java requires you to acknowledge (`throws IOException`, or try/catch).
- `hasNext()` combined with a `while` loop is the standard pattern for reading an entire file, line by line.
- `String.split(",")` breaks a CSV line into fields.
- The first line of a CSV is often column names, not values — skip it before parsing rows as real data.
- Reading rows into custom objects (one object per line) is cleaner than working with raw split arrays once the data has real structure.
