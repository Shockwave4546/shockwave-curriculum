# Implementing ArrayList Algorithms — Worked Example

## Problem

Across this season's events, track the ranking points earned at each one. Compute the average, check whether any two events earned the exact same number of points, and rotate the list right by one so the most recent event displays first — keeping a parallel list of event names in sync the whole time.

## Step 1: Plan It First

1. Store ranking points per event, and the matching event names alongside them.
2. Compute the average.
3. Check for two events with the exact same points total.
4. Rotate both lists right by one, in sync.

```java
ArrayList<String> eventNames = new ArrayList<String>();
eventNames.add("Week 1");
eventNames.add("Week 3");
eventNames.add("District Champs");

ArrayList<Integer> rankingPoints = new ArrayList<Integer>();
rankingPoints.add(18);
rankingPoints.add(24);
rankingPoints.add(18);
```

`rankingPoints.add(18)` autoboxes the `int` `18` into an `Integer` — `ArrayList` can only hold objects.

## Step 2: Average

Every pattern from Lesson 9.5 applies here too — just swap `[i]`/`.length` for `get(i)`/`.size()`:

```java
public static double average(ArrayList<Integer> points)
{
    double sum = 0;
    for (int i = 0; i < points.size(); i++)
    {
        sum += points.get(i);
    }
    return sum / points.size();
}
```

```java
System.out.println(average(rankingPoints)); // 20.0
```

## Step 3: Two Events With the Exact Same Points — Use `.equals()`

`rankingPoints` holds boxed `Integer` objects, so comparing with `==` would check identity, not value — `.equals()` is required instead:

```java
public static boolean hasMatchingTotal(ArrayList<Integer> points)
{
    for (int i = 0; i < points.size(); i++)
    {
        for (int j = i + 1; j < points.size(); j++)
        {
            if (points.get(i).equals(points.get(j))) // .equals(), not ==
            {
                return true;
            }
        }
    }
    return false;
}
```

```java
System.out.println(hasMatchingTotal(rankingPoints)); // true — Week 1 and District Champs both earned 18
```

## Step 4: Rotate Both Lists Right by One, In Sync

`eventNames` and `rankingPoints` are **parallel ArrayLists** — `rankingPoints.get(i)` is the points total for `eventNames.get(i)`. Rotating one without the other would break that pairing, so both need the identical rotation:

```java
public static void rotateRight(ArrayList<String> names, ArrayList<Integer> points)
{
    String lastName = names.get(names.size() - 1);
    int lastPoints = points.get(points.size() - 1);

    for (int i = names.size() - 1; i > 0; i--)
    {
        names.set(i, names.get(i - 1));
        points.set(i, points.get(i - 1));
    }

    names.set(0, lastName);
    points.set(0, lastPoints);
}
```

```java
rotateRight(eventNames, rankingPoints);
System.out.println(eventNames);    // [District Champs, Week 1, Week 3]
System.out.println(rankingPoints); // [18, 18, 24]
```

`eventNames.get(0)` is still `"District Champs"` and `rankingPoints.get(0)` is still `18` — the pairing survived the rotation because both lists were rotated the same way, in the same loop.

## Recap

- Every array algorithm pattern (accumulator, min/max, search, property checks, duplicates, rotate, reverse) transfers directly to `ArrayList` — just swap `[i]`/`.length` for `get(i)`/`.size()`.
- Compare `ArrayList` elements with `.equals()`, not `==`, when the element type is an object (including boxed numbers like `Integer`).
- Parallel `ArrayList`s keep related data in sync by index, same as parallel arrays — any operation that reorders one must reorder the other identically.
