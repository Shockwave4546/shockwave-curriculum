# Documentation with Comments and Preconditions — Worked Example

## Problem

Write a method your teammates can call to scale a joystick value (normally between -1.0 and 1.0) down to 75% power, for rookie drivers practicing on the drivetrain. Document it so a teammate knows what's safe to pass in without reading the method body — then show what happens if someone ignores the documentation.

## Step 1: Write the Method First

```java
public static double scaleForRookie(double joystickValue)
{
    return joystickValue * 0.75;
}
```

No documentation yet — just the behavior: multiply whatever comes in by `0.75`.

## Step 2: Decide the Precondition

For this method to do what it promises, `joystickValue` has to already be a real joystick reading: between `-1.0` and `1.0`. That's the **precondition** — what has to be true before the method is called.

## Step 3: Decide the Postcondition

If the precondition holds, the method guarantees its result is between `-0.75` and `0.75`. That's the **postcondition** — what's guaranteed true after the method runs.

## Step 4: Write the Documentation Comment

```java
/**
 * @param joystickValue the raw joystick input
 * Precondition: joystickValue is between -1.0 and 1.0.
 * Postcondition: returns joystickValue scaled to 75% power, between -0.75 and 0.75.
 */
public static double scaleForRookie(double joystickValue)
{
    return joystickValue * 0.75;  // scale down for rookie practice mode
}
```

The `/** ... */` block is a documentation comment — it describes the method for other programmers. The `//` on the return line is a single-line comment, just a quick note next to the code it explains. Both are ignored completely by the compiler.

## Step 5: Put It in a File

```java
/* RookieMode.java
   Scales joystick input down for rookie drivers practicing on the drivetrain. */
public class RookieMode
{
    public static void main(String[] args)
    {
        double scaled = scaleForRookie(0.8);
        System.out.println(scaled);
    }

    /**
     * @param joystickValue the raw joystick input
     * Precondition: joystickValue is between -1.0 and 1.0.
     * Postcondition: returns joystickValue scaled to 75% power, between -0.75 and 0.75.
     */
    public static double scaleForRookie(double joystickValue)
    {
        return joystickValue * 0.75;  // scale down for rookie practice mode
    }
}
```

The `/* ... */` block above the class is a plain multi-line comment — good for a longer file-level note that isn't documenting one specific method the way `/** */` does. This program now uses all three comment styles: `/* */` for the file-level note, `/** */` for documenting `scaleForRookie`, and `//` for the short inline note on its return line.

`0.8` satisfies the precondition, so the postcondition holds too: `scaled` prints `0.6`, safely inside `-0.75` to `0.75`.

## Step 6: Call It With a Value That Breaks the Precondition

```java
double broken = scaleForRookie(5.0);
System.out.println(broken);
```

`5.0` isn't a real joystick value — it violates the precondition. Java doesn't stop this call or throw any kind of error. `scaleForRookie` just does the multiplication anyway: `broken` prints `3.75`, which breaks the postcondition it promised (`-0.75` to `0.75`). Nothing crashed; the method silently returned a wrong-by-contract answer, the same way `Math.sqrt(-4)` silently returns `NaN`.

## Why This Matters Here

`scaleForRookie` never checks its input — nothing in Java forces it to. The documentation comment is the only place a teammate can learn "don't pass anything outside -1.0 to 1.0" without reading the method's one-line body. Skipping that comment doesn't break the method; it just means the next person has to guess, or find out the hard way.

## Recap

- `//`, `/* */`, and `/** */` are the three comment styles; the compiler ignores all of them.
- A precondition is what must be true before a method is called; a postcondition is what's guaranteed true after it returns.
- Preconditions are documented expectations, not automatically enforced — violating one can produce a wrong result without an error, as `scaleForRookie(5.0)` shows.
