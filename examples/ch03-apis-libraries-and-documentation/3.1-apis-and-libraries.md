# APIs and Libraries — Worked Example

## Problem

Your team's match code needs to know how much time has passed since the autonomous period started. WPILib's `Timer` class is a library class built for exactly this. Use it to start a stopwatch and print the elapsed time.

## Step 1: Find the Class and Its Behaviors

Before writing anything, identify the library piece you need: `Timer` is a class from WPILib. Its API tells you it has behaviors like `start()` (begin counting) and `get()` (return the seconds elapsed since `start()` was called). You don't need to know how `Timer` measures time internally — just what its behaviors do.

## Step 2: Set Up the Class and `main`

```java
public class MatchClock
{
    public static void main(String[] args)
    {

    }
}
```

Same skeleton as any Java program: a class to hold the code, and `main` as the entry point. Nothing prints yet.

## Step 3: Create a `Timer` Object

```java
public class MatchClock
{
    public static void main(String[] args)
    {
        Timer autoTimer = new Timer();
    }
}
```

`autoTimer` is an object — one specific `Timer`, built with `new`. `Timer` is the blueprint; `autoTimer` is the thing built from it.

## Step 4: Call a Behavior

```java
autoTimer.start();
```

The dot operator reaches into `autoTimer` and runs the `start` behavior defined by the `Timer` class. Nothing prints yet — `start()` just begins counting.

## Step 5: Call a Behavior That Returns a Value

```java
double autoElapsed = autoTimer.get();
System.out.println(autoElapsed);
```

`get()` is a behavior that hands back a value — the seconds elapsed — which is stored in the `double` variable `autoElapsed`, then printed.

## What the API Hid From You

Nowhere in this program did you write any code that measures time, reads a clock, or does math with timestamps. `Timer`'s API — `start()` and `get()` — is all you needed; the implementation is WPILib's problem, not yours.

## Recap

- A library is reusable code written by someone else; its API documents how to use it. `Timer` is a WPILib library class — you only needed to know its API, not its internals.
- A class defines a new kind of value, bundling attributes (data) and behaviors (methods) together. `Timer` bundles elapsed-time tracking behind the `start()` and `get()` behaviors.
- An object is one specific instance built from a class. `autoTimer` is one specific `Timer`, built with `new`; a robot could build another `Timer` object the same way for a different purpose, and the two would track time independently.
- The dot operator (`.`) accesses an object's attributes and behaviors — `autoTimer.start()` and `autoTimer.get()`.
