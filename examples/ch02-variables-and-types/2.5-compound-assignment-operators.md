# Compound Assignment Operators — Worked Example

**Outline ref:** 2.5 — Compound Assignment Operators (CSA 1.6)
**Pairs with:** [`lessons/ch02-variables-and-types/2.5-compound-assignment-operators.md`](../../lessons/ch02-variables-and-types/2.5-compound-assignment-operators.md)
**Status:** new — authored worked example (fully solved, walked step by step — not a problem to attempt)

## Problem

A flywheel's power decays slightly between shots (motors coast down a bit). After each of 3 shots, reduce the power by 10% — but never let it drop below a safety floor of `0.50`.

## Step 1: Plan It First

1. Start with a power level and a safety floor.
2. After each shot: reduce power by 10%.
3. Check power hasn't dropped below the floor — clamp it back up if it has.
4. Print the final power after all 3 shots.

There's no loop here yet (that's Ch.5) — three shots means writing the same two lines three times, in order.

## Step 2: Set Up the Class, `main`, and Starting Values

```java
public class FlywheelDecay
{
    public static void main(String[] args)
    {
        double flywheelPower = 0.65;
        double minPower = 0.50;
    }
}
```

## Step 3: Shot 1

```java
flywheelPower *= 0.9;
if (flywheelPower < minPower) {
    flywheelPower = minPower;
}
```

`flywheelPower *= 0.9` is shorthand for `flywheelPower = flywheelPower * 0.9` — it takes the *old* power, multiplies it by `0.9`, and stores the result back. Starting at `0.65`, that's `0.585`, still above the `0.50` floor, so the `if` doesn't fire.

State after shot 1: `flywheelPower = 0.585`.

## Step 4: Shot 2

Same two lines again:

```java
flywheelPower *= 0.9;
if (flywheelPower < minPower) {
    flywheelPower = minPower;
}
```

`0.585 * 0.9` is `0.5265`. Still above `0.50` — the clamp still doesn't trigger, but only barely this time.

State after shot 2: `flywheelPower = 0.5265`.

## Step 5: Shot 3

```java
flywheelPower *= 0.9;
if (flywheelPower < minPower) {
    flywheelPower = minPower;
}
```

`0.5265 * 0.9` is `0.47385` — this time it's *below* `0.50`, so the `if` condition is true and the body runs: `flywheelPower` gets overwritten back up to `0.50`. This is the one shot out of three where the safety floor actually does something.

State after shot 3: `flywheelPower = 0.50`.

## Step 6: Print the Final Status

```java
System.out.println("Flywheel power: " + flywheelPower);
```

Output:

```
Flywheel power: 0.5
```

## Recap

- `+= -= *= /= %=` update a variable using its current value, then store the result back — `flywheelPower *= 0.9` here.
- `++` and `--` work the same way for adding or subtracting exactly 1, one step at a time, same as any other compound operator.
- Decaying a flywheel's power down gradually is a real use of a compound operator, checked against a safety floor each time — the same shape as ramping a motor up to a ceiling.
- Tracing code by hand — one line, one value at a time — is how we found the clamp does nothing for shots 1 and 2, then actually fires on shot 3, without running anything.
