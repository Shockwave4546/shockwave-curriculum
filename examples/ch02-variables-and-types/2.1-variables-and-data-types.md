# Variables & Data Types — Worked Example

## Problem

Track the cargo intake subsystem's status: how many balls it has counted, how fast its belt is running, whether it's currently jammed, and what the subsystem is called — then print a one-line status report.

## Step 1: Plan It First

In plain English, before any code:

1. Store the ball count.
2. Store the belt speed.
3. Store whether it's jammed.
4. Store the subsystem's name.
5. Print all four in one status line.

Four pieces of data, four variables — the plan tells us that before we've picked a single type.

## Step 2: Set Up the Class and `main`

```java
public class IntakeStatus
{
    public static void main(String[] args)
    {

    }
}
```

Same skeleton every program starts from: a `class` matching the filename (`IntakeStatus.java`), and the `main` method inside it.

## Step 3: Pick a Type for Each Piece of Data

This is the judgment call the lesson is actually about — matching the type to what the value *is*:

- Ball count → a whole number, never a fraction of a ball → `int`.
- Belt speed → a percentage like `0.75` → needs a decimal → `double`.
- Jammed or not → only two possible states → `boolean`.
- Subsystem name → text → `String`.

## Step 4: Declare the Ball Count on Its Own

Do this one in two steps, the way the lesson first introduces declaration — declare it, *then* assign it:

```java
int ballCount;
ballCount = 3;
```

`ballCount` exists the moment it's declared, but it holds nothing until the `=` line runs. Read that second line as **`ballCount` gets assigned the value `3`.**

## Step 5: Declare the Rest, Combined

The other three don't need the two-step treatment — declare and assign in one line, like most code actually looks:

```java
double beltSpeed = 0.75;
boolean isJammed = false;
String subsystemName = "Intake";
```

## Step 6: Print the Status Line

```java
System.out.println("Subsystem: " + subsystemName);
System.out.println("Ball count: " + ballCount);
System.out.println("Belt speed: " + beltSpeed);
System.out.println("Jammed? " + isJammed);
```

`subsystemName`, `ballCount`, `beltSpeed`, and `isJammed` are all bare — no quotes — because we want the *value stored in the box*, not the literal word. Only the label text (`"Subsystem: "`, etc.) goes inside `""`.

## Step 7: Check the Naming

- `IntakeStatus` — PascalCase, it's a class name.
- `ballCount`, `beltSpeed`, `isJammed`, `subsystemName` — camelCase, and each name says exactly what the value is.
- `int`, `double`, `boolean`, `String`, `public`, `static`, `void` are all lowercase types/keywords — never chosen by you, always spelled exactly this way.

## The Finished Program

```java
public class IntakeStatus
{
    public static void main(String[] args)
    {
        int ballCount;
        ballCount = 3;

        double beltSpeed = 0.75;
        boolean isJammed = false;
        String subsystemName = "Intake";

        System.out.println("Subsystem: " + subsystemName);
        System.out.println("Ball count: " + ballCount);
        System.out.println("Belt speed: " + beltSpeed);
        System.out.println("Jammed? " + isJammed);
    }
}
```

Output:

```
Subsystem: Intake
Ball count: 3
Belt speed: 0.75
Jammed? false
```

## What Would Break This

If Step 4 had written `int ballCount = 3.0;` instead, it wouldn't compile — `3.0` is a `double` literal, and its decimal point doesn't fit in an `int` box. The type has to match what the value actually is, not just what number it looks like.

## Recap

- Java has exactly 8 primitive types; `int`, `double`, and `boolean` covered three of our four values here, and `String` (built out of `char`s) covered the fourth.
- A variable is a named box that holds a value, and that value can change.
- `=` means "gets assigned," not "equals" — declaring and assigning can happen in one line or two.
- A variable declared inside `main` is a local variable — it only exists inside that method.
- Variable names use camelCase and should describe what the value is; class names use PascalCase.
