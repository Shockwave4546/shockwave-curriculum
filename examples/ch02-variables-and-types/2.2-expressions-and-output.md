## Problem

Build a small pre-match readout: split the autonomous period's remaining time (in total seconds) into minutes and seconds, then print the total score from three scoring events using the correct order of operations.

## Step 1: Plan It First

1. Store the remaining time as total seconds.
2. Split it into whole minutes and leftover seconds.
3. Print the time as `M:SS`-style output.
4. Compute and print a total score from three separate point values.

## Step 2: Set Up the Class and `main`

```java
public class MatchReadout
{
    public static void main(String[] args)
    {

    }
}
```

## Step 3: Store the Remaining Time

```java
int secondsLeft = 137;
```

An `int` — a countdown clock counts whole seconds, no fractions.

## Step 4: Split It with `/` and `%`

```java
System.out.print("Time remaining: ");
System.out.print(secondsLeft / 60);
System.out.print(":");
System.out.println(secondsLeft % 60);
```

`secondsLeft / 60` is `137 / 60`, which is `2` — whole-number division throws away the remainder, and here that's exactly what we want (whole minutes). `secondsLeft % 60` is `17`, the leftover seconds `/` can't express. Notice this line uses `print`, not `println`, three times in a row before finally calling `println` — each `print` keeps the cursor on the same line, so `2`, `:`, and `17` all land on one line: `Time remaining: 2:17`.

## Step 5: Compute the Total Score with Order of Operations

Three scoring events this match: 2 points scored 3 separate times, plus a 5-point bonus.

```java
System.out.println(2 * 3 + 5);   // 11 — multiplication happens before addition
System.out.println(2 * (3 + 5)); // 16 — parentheses override that
```

`2 * 3 + 5` is *not* read left to right like plain text — `*` binds tighter than `+`, so it's `(2 * 3) + 5 = 11`. The parenthesized version forces `3 + 5` to happen first instead, giving a very different answer, `16`. Only one of these is the score we actually meant (`11`, three 2-point scores plus a 5-point bonus) — the parenthesized version is a different (wrong, for this problem) calculation shown for contrast.

## Recap

- `print` stays on the line; `println` moves to a new one — chaining several `print` calls builds one line piece by piece.
- Dividing two whole numbers (like `secondsLeft / 60`) truncates the decimal part instead of rounding — exactly why it works for splitting a total into whole minutes.
- Use `*`/`/` before `+`/`-`, unless parentheses say otherwise — the same expression can mean two different things depending on where the parentheses go.
- `%` gives the remainder after division — useful for splitting a total into two units (like seconds into minutes and seconds).
