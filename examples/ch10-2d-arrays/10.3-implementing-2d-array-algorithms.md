# Implementing 2D Array Algorithms — Worked Example

## Problem

During shooter practice, the team took 10 shots from each of 3 spots on the field (left, center, right) at each of 4 distances (nearest to farthest), and recorded how many went in. Find the total made from one spot, the total made at one distance, the best single result, how many results in a chosen range made at least 5, and whether any two results are exactly equal. Then reverse one spot's row so it reads farthest distance first.

## Step 1: Plan It First

Six small tasks, each one a 1D pattern from Lesson 9.5 applied to a 2D array:

1. Total from one spot: sum a row (fix the row, loop the columns).
2. Total at one distance: sum a column (fix the column, loop the rows).
3. Best single result: running max over the whole grid.
4. Results of at least 5 in a range: property count over a subsection.
5. Any two equal results: duplicate check (4 nested loops).
6. Farthest distance first for one spot: reverse a single row in place.

```java
int[][] shotsMade =
{
    {7, 6, 4, 2}, // left spot
    {9, 8, 5, 3}, // center spot
    {6, 5, 5, 1}, // right spot
};
```

## Step 2: Total From One Spot (Sum a Row)

The row is fixed by the parameter, so only the column changes:

```java
public static int getTotalForSpot(int row, int[][] a)
{
    int total = 0;
    for (int col = 0; col < a[0].length; col++)
    {
        total = total + a[row][col];
    }
    return total;
}
```

```java
System.out.println(getTotalForSpot(1, shotsMade)); // 25 — center spot: 9 + 8 + 5 + 3
```

## Step 3: Total at One Distance (Sum a Column)

Now the column is fixed and the row changes. The loop bound switches to `a.length`, the row count:

```java
public static int getTotalForDistance(int col, int[][] a)
{
    int total = 0;
    for (int row = 0; row < a.length; row++)
    {
        total = total + a[row][col];
    }
    return total;
}
```

```java
System.out.println(getTotalForDistance(0, shotsMade)); // 22 — nearest distance: 7 + 9 + 6
```

## Step 4: Best Single Result (Running Max)

Seed `best` with a real element, `a[0][0]`, not `0`. Then check every cell with nested loops:

```java
public static int getBestResult(int[][] a)
{
    int best = a[0][0];
    for (int row = 0; row < a.length; row++)
    {
        for (int col = 0; col < a[0].length; col++)
        {
            if (a[row][col] > best)
            {
                best = a[row][col];
            }
        }
    }
    return best;
}
```

```java
System.out.println(getBestResult(shotsMade)); // 9 — center spot, nearest distance
```

## Step 5: Results of at Least 5 in a Range (Subsection Count)

The coach only wants the left and center spots (rows `0` to `1`) at the two middle distances (columns `1` to `2`). Narrowing the loop bounds covers just that rectangle. The end bounds are inclusive, so the loops use `<=`:

```java
public static int countAtLeast(int minMade, int[][] a,
                               int rowStart, int rowEnd, int colStart, int colEnd)
{
    int count = 0;
    for (int row = rowStart; row <= rowEnd; row++)
    {
        for (int col = colStart; col <= colEnd; col++)
        {
            if (a[row][col] >= minMade)
            {
                count++;
            }
        }
    }
    return count;
}
```

```java
System.out.println(countAtLeast(5, shotsMade, 0, 1, 1, 2)); // 3 — checks 6, 4, 8, 5
```

With `<` instead of `<=`, the loops would stop at row `0` and column `1`, and only one cell (the `6`) would be checked.

## Step 6: Any Two Equal Results (Duplicate Check)

Two loops pick a candidate cell. Two more loops compare it against every cell that comes *after* it: later columns in the same row, then every column of every later row. The inner column loop's starting point depends on which row it's in, so an `if` sets `startCol` before that loop begins:

```java
public static boolean hasDuplicateResult(int[][] a)
{
    for (int row = 0; row < a.length; row++)
    {
        for (int col = 0; col < a[0].length; col++)
        {
            for (int row2 = row; row2 < a.length; row2++)
            {
                int startCol = 0;
                if (row2 == row)
                {
                    startCol = col + 1;
                }
                for (int col2 = startCol; col2 < a[0].length; col2++)
                {
                    if (a[row][col] == a[row2][col2])
                    {
                        return true;
                    }
                }
            }
        }
    }
    return false;
}
```

```java
System.out.println(hasDuplicateResult(shotsMade)); // true — the left spot's 6 matches the right spot's 6
```

The first pair it finds is `a[0][1]` (left spot, `6`) and `a[2][0]` (right spot, `6`), which are in different rows. That's why the later-rows part of the search matters. A check that only compared cells within the same row would find the two `5`s in the right spot's row eventually, but it would miss matches like this one completely.

## Step 7: Farthest Distance First for One Spot (Reverse a Single Row)

One row of a 2D array is a plain 1D array, so this is exactly the 1D reverse from Lesson 9.5: swap from both ends toward the middle. The row index just stays fixed:

```java
public static void reverseRow(int[][] a, int row)
{
    int start = 0;
    int end = a[0].length - 1;
    while (start < end)
    {
        int temp = a[row][start];
        a[row][start] = a[row][end];
        a[row][end] = temp;
        start++;
        end--;
    }
}
```

```java
reverseRow(shotsMade, 0);
// left spot's row is now: 2, 4, 6, 7 — the other two rows are unchanged
```

## Recap

- Summing a row fixes the row and loops the columns (bound `a[0].length`). Summing a column fixes the column and loops the rows (bound `a.length`).
- A running max over the whole grid needs nested loops and is seeded with a real element, `a[0][0]`.
- A subsection is just narrower loop bounds. Check whether the end bounds are inclusive (`<=`) or not.
- A full duplicate check needs 4 nested loops. `startCol` makes the search begin just after the candidate in its own row, and at column `0` in every later row.
- Reversing one row reuses the 1D swap-from-both-ends pattern, with the row index held fixed.
