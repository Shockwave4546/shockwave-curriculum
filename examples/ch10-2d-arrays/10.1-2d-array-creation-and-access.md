# 2D Array Creation and Access — Worked Example

## Problem

A scout tracks autonomous points for the 3 robots on the team's alliance across 4 practice matches. Set up a blank scouting sheet, then store the real results, read one robot's score from one match, fix a value the scout entered wrong, and find how many robots and how many matches the sheet holds.

## Step 1: Plan It First

1. One row per robot, one column per match — 3 rows, 4 columns.
2. A blank sheet first (created with `new`), then the real results (an initializer list).
3. Read one element with `[row][col]`, then overwrite one.
4. Row count from `.length`, column count from the length of one row.

## Step 2: A Blank Sheet — Created With `new`

```java
int[][] blankSheet = new int[3][4]; // 3 robots, 4 matches each
System.out.println(blankSheet[1][2]); // 0
```

Every one of the 12 elements starts at `int`'s default value, `0` — nothing has actually been recorded yet. A blank sheet created this way holds no real data until each slot gets assigned.

## Step 3: The Real Results — an Initializer List

When the values are already known, one inner list per row fills the whole array in one step, and Java works out the size (3 rows, 4 columns) from the lists themselves:

```java
int[][] autoPoints =
{
    {6, 9, 3, 12},   // robot 1
    {15, 15, 9, 18}, // robot 2
    {3, 0, 6, 6},    // robot 3
};
```

## Step 4: Read One Element — `[row][col]`

The first index picks the robot (the row), the second picks the match (the column). Both start at `0`, so robot 2's 4th match is row `1`, column `3`:

```java
int robot2Match4 = autoPoints[1][3];
System.out.println(robot2Match4); // 18
```

Swapping the indices would ask a different question: `autoPoints[3][1]` means "row 3" — but only rows `0` to `2` exist, so it throws `ArrayIndexOutOfBoundsException`.

## Step 5: Fix a Wrong Entry

The scout realizes robot 3 actually scored 3 points in match 2, not 0. Assigning to `[row][col]` overwrites just that one element:

```java
autoPoints[2][1] = 3;
System.out.println(autoPoints[2][1]); // 3
```

## Step 6: How Many Robots, How Many Matches

```java
System.out.println(autoPoints.length);    // 3 — rows (robots)
System.out.println(autoPoints[0].length); // 4 — columns (matches per robot)
```

`autoPoints[0].length` works because `autoPoints[0]` is a complete 1D array on its own — robot 1's whole row:

```java
int[] robot1Row = autoPoints[0];
System.out.println(robot1Row[0]); // 6 — same element as autoPoints[0][0]
```

Those counts also give the last valid index in each direction — `autoPoints.length - 1` for rows, `autoPoints[0].length - 1` for columns:

```java
System.out.println(autoPoints[autoPoints.length - 1][autoPoints[0].length - 1]); // 6 — robot 3, match 4
```

## Recap

- `new int[3][4]` creates a 3-row, 4-column array of all `0`s — the structure exists, but no real data is in it yet.
- A nested initializer list (one inner list per row) creates and fills a 2D array in one step.
- `arr[row][col]` reads or writes one element; the first index is always the row.
- `arr.length` is the row count; `arr[0].length` is the column count, because each row is a real 1D array.
