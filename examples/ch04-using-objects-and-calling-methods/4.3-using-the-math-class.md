# Using the Math Class — Worked Example

## Problem

Find the diagonal brace length needed for a rectangular support frame, given its width and height, using `Math.pow` and `Math.sqrt`. Then pick a random index (0-3) for one of four practice autonomous routines, using `Math.random()`.

## Step 1: Plan It First

1. Store the frame's width and height.
2. Square each one and add them together, using `Math.pow`.
3. Take the square root of that sum, using `Math.sqrt` — the diagonal.
4. Pick a random index from 0-3 for the practice routine, using `Math.random()`.

## Step 2: Store the Width and Height

```java
double frameWidth = 24.0;
double frameHeight = 18.0;
```

## Step 3: Square Each Side with `Math.pow`

`Math` is a built-in class of static methods — no object, no `new`, just call it directly by its class name:

```java
double widthSquared = Math.pow(frameWidth, 2);
double heightSquared = Math.pow(frameHeight, 2);
```

`Math.pow(frameWidth, 2)` raises `frameWidth` to the 2nd power. Like every `Math` method, this returns a value, so it has to be stored or used — here it's stored in `widthSquared`.

## Step 4: Take the Square Root

```java
double diagonal = Math.sqrt(widthSquared + heightSquared);
System.out.println("Diagonal brace length: " + diagonal);
```

Put together:

```java
public class FrameBrace
{
    public static void main(String[] args)
    {
        double frameWidth = 24.0;
        double frameHeight = 18.0;

        double widthSquared = Math.pow(frameWidth, 2);
        double heightSquared = Math.pow(frameHeight, 2);

        double diagonal = Math.sqrt(widthSquared + heightSquared);
        System.out.println("Diagonal brace length: " + diagonal);
    }
}
```

This prints:

```
Diagonal brace length: 30.0
```

(`24² + 18² = 900`; `√900 = 30.0` — an 18-24-30 triangle, a scaled-up 3-4-5.)

## Step 5: Pick a Random Practice Routine

`Math.random()` alone gives a `double` in `[0.0, 1.0)`. To get a whole-number index from 0-3 (4 possible practice routines), multiply by the range size and cast to `int`:

```java
int routineIndex = (int)(Math.random() * 4);
System.out.println("Practice routine: " + routineIndex);
```

The range size is `4` because there are 4 routines to choose from (indices `0` through `3`) — not `3`, which would leave index `3` unreachable.

## Step 6: What the Parentheses Are Protecting Against

If the cast only wrapped `Math.random()` instead of the whole scaled expression —

```java
int routineIndex = (int)Math.random() * 4; // wrong — always 0
```

— `Math.random()` (something like `0.612`) would be cast to `int` *first*, truncating it straight down to `0`, and only then multiplied by `4`. The result is `0`, every single time, no matter what `Math.random()` actually returned. The parentheses in Step 5 around `(Math.random() * 4)` make sure the multiplication happens before the cast.

## Recap

- `Math` methods are static — called them as `Math.pow(frameWidth, 2)` and `Math.sqrt(...)`, no object needed.
- `Math.random()` returns a `double` in `[0.0, 1.0)` — 0.0 possible, 1.0 never reached.
- To get a random int in a range: `(int)(Math.random() * range) + min` — here `range` was `4` and `min` was `0`, giving indices 0-3.
- The parentheses around `Math.random() * range` are required — casting only `Math.random()` first would have made `routineIndex` always `0`.
