      <p class="lead">Unlike static methods, an <strong>instance method</strong> only makes sense on a specific object — it reads or changes that object's own state.</p>
      <ul class="bullets">
        <li><span class="bul">▸</span><span>Calling a method on a <span class="k">null</span> reference — an object that was never created — throws a <span class="t">NullPointerException</span>.</span></li>
        <li><span class="bul">▸</span><span>A <strong>getter</strong> (like <span class="me">getVelocity()</span>) just reports state — its return value must be used, not ignored.</span></li>
      </ul>
    </div>
