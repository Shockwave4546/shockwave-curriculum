  <div class="two">
    <div>
      <p class="lead">A method's <strong>signature</strong> is its name plus its parameter types. A <strong>parameter</strong> is a variable declared in the header; an <strong>argument</strong> is the actual value passed in when it's called.</p>
      <ul class="bullets">
        <li><span class="bul">▸</span><span>Java uses <strong>call by value</strong> — the method gets a copy of the argument, not the original.</span></li>
        <li><span class="bul">▸</span><span>Two methods can share a name if their parameter lists differ — this is called <strong>overloading</strong>.</span></li>
      </ul>
    </div>
    <div class="code">
      <span class="cl"><span class="c">// Signature: rampTo(double) — name + parameter type</span></span>
      <span class="cl"><span class="k">public void</span> <span class="me">rampTo</span>(<span class="k">double</span> targetSpeed) { ... }</span>
      <span class="cl">&nbsp;</span>
      <span class="cl"><span class="c">// Call: 0.8 is the argument, copied into targetSpeed</span></span>
