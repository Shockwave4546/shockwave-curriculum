## Multiple Choice

**Question:** A teammate writes `Gyro navXGyro = new Gyro(); double heading = navXGyro.getAngle();`. Which statement correctly identifies the class and the object?

**Options:**

- A. `Gyro` is the class; `navXGyro` is the object built from it.
- B. `navXGyro` is the class; `Gyro` is the object built from it.
- C. `getAngle` is the class; `navXGyro` is the object.
- D. `Gyro` and `navXGyro` are both objects — there is no class here.

**Answer:** A

**Why:** `Gyro` is the blueprint — the class from the library — and `navXGyro` is one specific instance built from it with `new`. Calling `navXGyro.getAngle()` reaches a behavior defined by the `Gyro` class and runs it on this one object.

- B is wrong — it swaps the roles: `Gyro` is the class (the blueprint), not something built from `navXGyro`.
- C is wrong — `getAngle` is a behavior (method) defined by the class, not the class itself.
- D is wrong — every object is built from some class; `Gyro` is that class here, not another object.

## Micro-Parsons

**Problem:** These lines, once correctly ordered, form a complete program that creates an `Ultrasonic` object, pings it, reads the resulting distance, and prints that value.

Reorder the fragments below into a working program:

- a. `        double distanceInches = frontSensor.getRangeInches();`
- b. `    public static void main(String[] args)`
- c. `    }`
- d. `public class ProximityCheck`
- e. `        Ultrasonic frontSensor = new Ultrasonic(0, 1);`
- f. `}`
- g. `{`
- h. `        System.out.println(distanceInches);`
- i. `    {`
- j. `        frontSensor.ping();`

**Answer:** d, g, b, i, e, j, a, h, c, f

```java
public class ProximityCheck
{
    public static void main(String[] args)
    {
        Ultrasonic frontSensor = new Ultrasonic(0, 1);
        frontSensor.ping();
        double distanceInches = frontSensor.getRangeInches();
        System.out.println(distanceInches);
    }
}
```

**Why this order:** The class line (`d`) has to come first, with its opening brace (`g`) right after. `main` (`b`) is the entry point, declared next, followed by its own opening brace (`i`). Inside `main`, the `Ultrasonic` object must be created (`e`) before any behavior can be called on it. `ping()` (`j`) is a behavior that doesn't return anything, so it's just called on its own line. `getRangeInches()` (`a`) is a behavior that *does* return a value, so it has to be stored in the `distanceInches` variable before that variable can be printed (`h`). Then the braces close in the reverse order they opened: `main`'s body first (`c`), then the class's body (`f`).
