## Problem: Fix the First Program

This program is supposed to print two lines, but it won't compile. Find every mistake and fix it. Write your code in a real IDE (or an online one) first, get it running, then check it against the solution below.

```java
public class Greeting
{
    public static void main(String[] args)
    {
        System.out.println("Welcome to the team!")
        system.out.println("Let's write some Java.);
    }
}
```

## Hints

- Every statement needs something at the end of it — check both lines.
- Java is case-sensitive. Is every word spelled with the capitalization Java expects?
- Every opening quote `"` needs a matching closing quote.

## Solution

```java
public class Greeting
{
    public static void main(String[] args)
    {
        System.out.println("Welcome to the team!");       // was missing a semicolon
        System.out.println("Let's write some Java.");      // "system" -> "System", and the closing quote was missing
    }
}
```

Two separate mistakes were hiding in that second line — a capitalization error (`system` instead of `System`) *and* a missing closing quote. This is normal: the compiler stops at the first error it finds, so fixing one bug sometimes reveals another one right behind it.
