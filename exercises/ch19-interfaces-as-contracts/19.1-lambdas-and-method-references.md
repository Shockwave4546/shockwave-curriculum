# Lambdas & Method References — Exercises

## Multiple Choice

**Question:** `beamBreak` is an object whose class has a method `public boolean isBlocked()`. A teammate wants a `BooleanSupplier` (from `java.util.function`, already imported) that reports whether the beam is blocked:

```java
BooleanSupplier hasPiece = ______;
```

Which of these, placed in the blank, does **not** compile?

**Options:**

- A. `() -> beamBreak.isBlocked()`
- B. `() -> { beamBreak.isBlocked(); }`
- C. `beamBreak::isBlocked`
- D. `() -> { return beamBreak.isBlocked(); }`

**Answer:** B

**Why:** `BooleanSupplier`'s one method takes no arguments and returns a `boolean`, so whatever goes in the blank has to produce a `boolean`. B uses a `{ }` block body but has no `return` — the call runs, but its result is thrown away and nothing is returned, so it doesn't compile. Only a single-expression body (no braces) returns its value automatically.

- A is wrong — it compiles. It's a single-expression body, so `beamBreak.isBlocked()`'s value is returned automatically.
- C is wrong — it compiles. It's a method reference, exact shorthand for A, since A's whole body is just one call to an existing method.
- D is wrong — it compiles. It uses a block body, but it includes the explicit `return` that a block body needs.

## Micro-Parsons

**Problem:** Given the import, class, and `main` signature below, reorder the fragments into the body of `main` (where the comment is). It should create a `DoubleSupplier` named `armAngle` using a multi-statement lambda: inside the lambda, declare a raw encoder reading of `97.5` and a mounting offset of `7.5`, then return the reading minus the offset. Finally, print the supplied value. The program should print `Arm angle: 90.0`.

```java
import java.util.function.DoubleSupplier;

public class ArmAngleCheck
{
    public static void main(String[] args)
    {
        // main body goes here
    }
}
```

Reorder the fragments below to complete it:

- a. `            return raw - offset;`
- b. `        System.out.println("Arm angle: " + armAngle.getAsDouble());`
- c. `            double offset = 7.5;`
- d. `        DoubleSupplier armAngle = () -> {`
- e. `        };`
- f. `            double raw = 97.5;`

**Answer:** d, f, c, a, e, b

**Interchangeable:** (f, c)

```java
import java.util.function.DoubleSupplier;

public class ArmAngleCheck
{
    public static void main(String[] args)
    {
        DoubleSupplier armAngle = () -> {
            double raw = 97.5;
            double offset = 7.5;
            return raw - offset;
        };
        System.out.println("Arm angle: " + armAngle.getAsDouble());
    }
}
```

**Why this order:** The lambda opens with `d` — the `() ->` takes no parameters, matching `DoubleSupplier`'s one method, `getAsDouble()`, and the `{` starts a multi-statement body. The two declarations (`f` and `c`) go inside it, in either order: neither one reads the other, so swapping them changes nothing. Both must come before `return raw - offset;` (`a`), which uses them — and because this is a block body, the explicit `return` is required. `};` (`e`) closes the lambda's body *and* ends the assignment statement, which is why it has a semicolon. Only then does the `println` (`b`) call `armAngle.getAsDouble()`, which runs the lambda's body and prints `90.0`. The import, class, and `main` signature are the given scaffold.
