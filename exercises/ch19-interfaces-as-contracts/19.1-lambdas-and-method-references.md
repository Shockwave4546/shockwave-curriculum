# Lambdas & Method References — Exercises

## Multiple Choice

**Question:** `beamBreak` is an object whose class has a method `public boolean isBlocked()`. A teammate wants a `BooleanSupplier` (from `java.util.function`, already imported) that reports whether the beam is blocked:

```java
BooleanSupplier hasPiece = ______;
```

Which of these, placed in the blank, does **not** compile?

**Options:**

- A. `() -> beamBreak.isBlocked()`
- B. `() -> { beamBreak.isBlocked(); }`
- C. `beamBreak::isBlocked`
- D. `() -> { return beamBreak.isBlocked(); }`

**Answer:** B

**Why:** `BooleanSupplier`'s one method takes no arguments and returns a `boolean`, so whatever goes in the blank has to produce a `boolean`. B uses a `{ }` block body but has no `return` — the call runs, but its result is thrown away and nothing is returned, so it doesn't compile. Only a single-expression body (no braces) returns its value automatically.

- A is wrong — it compiles. It's a single-expression body, so `beamBreak.isBlocked()`'s value is returned automatically.
- C is wrong — it compiles. It's a method reference, exact shorthand for A, since A's whole body is just one call to an existing method.
- D is wrong — it compiles. It uses a block body, but it includes the explicit `return` that a block body needs.

## Micro-Parsons

**Problem:** Given the import, class, and `main` signature below, reorder the fragments into the body of `main` (where the comment is). It should create a `DoubleSupplier` named `armAngle` using a multi-statement lambda: inside the lambda, declare a raw encoder reading of `97.5` and a mounting offset of `7.5`, then return the reading minus the offset. Finally, print the supplied value. The program should print `Arm angle: 90.0`.

```java
import java.util.function.DoubleSupplier;

public class ArmAngleCheck
{
    public static void main(String[] args)
    {
        // main body goes here
    }
}
```

Reorder the fragments below to complete it:

- a. `            return raw - offset;`
- b. `        System.out.println("Arm angle: " + armAngle.getAsDouble());`
- c. `            double offset = 7.5;`
- d. `        DoubleSupplier armAngle = () -> {`
- e. `        };`
- f. `            double raw = 97.5;`

**Answer:** d, f, c, a, e, b

**Interchangeable:** (f, c)

```java
import java.util.function.DoubleSupplier;

public class ArmAngleCheck
{
    public static void main(String[] args)
    {
        DoubleSupplier armAngle = () -> {
            double raw = 97.5;
            double offset = 7.5;
            return raw - offset;
        };
        System.out.println("Arm angle: " + armAngle.getAsDouble());
    }
}
```

**Why this order:** The lambda opens with `d` — the `() ->` takes no parameters, matching `DoubleSupplier`'s one method, `getAsDouble()`, and the `{` starts a multi-statement body. The two declarations (`f` and `c`) go inside it, in either order: neither one reads the other, so swapping them changes nothing. Both must come before `return raw - offset;` (`a`), which uses them — and because this is a block body, the explicit `return` is required. `};` (`e`) closes the lambda's body *and* ends the assignment statement, which is why it has a semicolon. Only then does the `println` (`b`) call `armAngle.getAsDouble()`, which runs the lambda's body and prints `90.0`. The import, class, and `main` signature are the given scaffold.

## Coding

**Mode:** full-program

**Problem:** Fill in the class `Wiring`, a set of four static methods that each **return a functional-interface object**.
Use lambdas and method references; you do not write any new classes besides `Wiring`.

- `static DoubleSupplier clamped(double raw)` returns a supplier that gives back `raw` limited to the range
  `-1.0` to `1.0` (use a lambda with a `{ }` body and an explicit `return`).
- `static IntBinaryOperation weightedSum(int weight)` returns an operation that computes `a + b * weight`
  (the lambda uses the `weight` parameter).
- `static Function<String, Integer> lengthOf()` returns a function that gives a string's length
  (a method reference does it in one word).
- `static Runnable stopAction(Motor motor)` returns a `Runnable` that calls `motor.stop()` when run
  (a bound method reference).

`IntBinaryOperation` and `Motor` are given. `main` reads a raw throttle, two ints, a weight and a name.

**Starter:**

```java
import java.util.Scanner;
import java.util.function.DoubleSupplier;
import java.util.function.Function;

public class Main
{
    public static void main(String[] args) // Don't change main
    {
        Scanner in = new Scanner(System.in);
        double raw = in.nextDouble();
        int a = in.nextInt();
        int b = in.nextInt();
        int weight = in.nextInt();
        String name = in.next();

        Motor motor = new Motor();
        DoubleSupplier speed = Wiring.clamped(raw);
        motor.setThrottle(speed.getAsDouble());
        System.out.println("Throttle: " + motor.getThrottle());

        IntBinaryOperation op = Wiring.weightedSum(weight);
        System.out.println("Weighted: " + op.apply(a, b));

        Function<String, Integer> length = Wiring.lengthOf();
        System.out.println("Name length: " + length.apply(name));

        Runnable stopAll = Wiring.stopAction(motor);
        stopAll.run();
        System.out.println("After stop: " + motor.getThrottle());
    }
}

    public double getThrottle()
    {
        return throttle;
    }

    public void stop()
    {
        throttle = 0.0;
```

**Solution:**

```java
import java.util.Scanner;
import java.util.function.DoubleSupplier;
import java.util.function.Function;

public class Main
{
    public static void main(String[] args) // Don't change main
    {
        Scanner in = new Scanner(System.in);
        double raw = in.nextDouble();
        int a = in.nextInt();
        int b = in.nextInt();
        int weight = in.nextInt();
        String name = in.next();

        Motor motor = new Motor();
        DoubleSupplier speed = Wiring.clamped(raw);
        motor.setThrottle(speed.getAsDouble());
        System.out.println("Throttle: " + motor.getThrottle());

        IntBinaryOperation op = Wiring.weightedSum(weight);
        System.out.println("Weighted: " + op.apply(a, b));

        Function<String, Integer> length = Wiring.lengthOf();
        System.out.println("Name length: " + length.apply(name));

        Runnable stopAll = Wiring.stopAction(motor);
        stopAll.run();
        System.out.println("After stop: " + motor.getThrottle());
    }
}

interface IntBinaryOperation
{
    int apply(int a, int b);
}

class Motor
{
    private double throttle = 0.0;

    public void setThrottle(double throttle)
    {
        this.throttle = throttle;
    }

    public double getThrottle()
    {
        return throttle;
    }

    public void stop()
    {
        throttle = 0.0;
    }
}

class Wiring
{
    public static DoubleSupplier clamped(double raw)
    {
        return () ->
        {
            return Math.max(-1.0, Math.min(1.0, raw));
        };
    }

    public static IntBinaryOperation weightedSum(int weight)
    {
        return (a, b) -> a + b * weight;
    }

    public static Function<String, Integer> lengthOf()
    {
        return String::length;
    }

    public static Runnable stopAction(Motor motor)
    {
        return motor::stop;
    }
}
```

**Why:** Each method hands back a different shape from the lesson's table. `clamped` needs a multi-statement body, so a `{ }` block with `return`
(or a single expression with `Math.max`/`Math.min`) works, and it reads the effectively-final parameter `raw`. `weightedSum` shows a two-parameter lambda that captures `weight`.
`String::length` is an unbound instance reference (the string arrives as the argument), and `motor::stop` is a bound reference to one specific `Motor`.
The usual mistakes are clamping only one side, so a large negative throttle comes back unchanged, and getting the order of operations wrong in `weightedSum`
(`(a + b) * weight` instead of `a + b * weight`).
