## Problem: Debug the Shooter Status Report

A teammate wrote this status-report code for the shooter subsystem, but it has 4 bugs — some won't compile, some compile but print the wrong thing. Find and fix all 4 before checking the solution below.

```java
public class ShooterStatus
{
    public static void main(String[] args)
    {
        int targetRPM = 4500.0;
        double currentRPM = 4480
        boolean isAtSpeed = 1;
        var name = "Shooter"

        System.out.print("Subsystem: ");
        System.out.println("name");
        System.out.println("Target RPM: " + targetRPM);
        System.out.println("At speed? " + isAtSpeed);
    }
}
```

## Hints

- One variable is declared with a type that can't hold the value being assigned to it.
- Two lines are missing something every Java statement needs.
- `boolean` only ever holds two specific literal values — `1` isn't one of them.
- Look closely at the `println("name")` line — is `name` inside or outside the quotes?

## Solution

```java
public class ShooterStatus
{
    public static void main(String[] args)
    {
        double targetRPM = 4500.0;   // bug 1: was `int`, but 4500.0 is a double literal
        double currentRPM = 4480;    // bug 2: missing semicolon
        boolean isAtSpeed = false;   // bug 3: boolean can only be true/false, not 1
        var name = "Shooter";        // bug 4: missing semicolon

        System.out.print("Subsystem: ");
        System.out.println(name);    // bug 5: "name" printed the literal text; needed `name` unquoted
        System.out.println("Target RPM: " + targetRPM);
        System.out.println("At speed? " + isAtSpeed);
    }
}
```

(That's actually 5 bugs once you count the quoted-variable mistake separately from the missing semicolons — worth noticing that "4 obvious bugs" often hides one more once you trace through carefully.)
