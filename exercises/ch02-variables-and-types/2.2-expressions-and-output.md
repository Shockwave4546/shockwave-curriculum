# Expressions & Output — Exercises

## Multiple Choice

**Question:** A student computes the average number of game pieces scored per match using `int avgPieces = totalPieces / matchCount;`, where `totalPieces = 17` and `matchCount = 5`. What value ends up stored in `avgPieces`?

**Options:**

- A. 3.4
- B. 3
- C. 4
- D. 3.5

**Answer:** B

**Why:** `totalPieces` and `matchCount` are both `int`, so `/` performs whole-number division — it computes `17 / 5` as `3`, throwing away the `.4` instead of keeping or rounding it.

- A is wrong because `3.4` is the mathematically exact answer, but `int` division never produces a decimal result in the first place, regardless of what `avgPieces` is declared as.
- C is wrong because `4` would be the result of rounding `3.4` to the nearest whole number, but truncating division never rounds.
- D is wrong because `3.5` isn't even the true mathematical average (`17 / 5` is `3.4`, not `3.5`), and int division wouldn't produce a decimal like this regardless.

## Micro-Parsons

**Problem:** These lines, once correctly ordered, form a program that stores a cable's length in inches, then prints how many full feet and how many leftover inches it contains, producing exactly this output on one line: `Feet: 4, Inches: 2`

Reorder the fragments below into a working program:

- a. `        System.out.print("Feet: " + cableLengthInches / 12 + ", ");`
- b. `public class CableLength`
- c. `    }`
- d. `}`
- e. `{`
- f. `    public static void main(String[] args)`
- g. `    {`
- h. `        int cableLengthInches = 50;`
- i. `        System.out.println("Inches: " + cableLengthInches % 12);`

**Answer:** b, e, f, g, h, a, i, c, d

```java
public class CableLength
{
    public static void main(String[] args)
    {
        int cableLengthInches = 50;

        System.out.print("Feet: " + cableLengthInches / 12 + ", ");
        System.out.println("Inches: " + cableLengthInches % 12);
    }
}
```

**Why this order:** The usual class/`main` skeleton (`b`, `e`, `f`, `g`) comes first. `cableLengthInches` (`h`) must be declared before either print statement can use it. `/` and `%` both bind tighter than `+`, so `cableLengthInches / 12` gives the whole number of feet (`4`) and `cableLengthInches % 12` gives the leftover inches (`2`) — exactly what this lesson's order-of-operations rule guarantees, with no parentheses needed. The `print` (`a`) has to come before the `println` (`i`) to match the required output — `print` leaves the cursor on the same line, so `println`'s text lands right after it, producing `Feet: 4, Inches: 2` on a single line. Then the braces close in the reverse order they opened: `main`'s body first (`c`), then the class's body (`d`).
