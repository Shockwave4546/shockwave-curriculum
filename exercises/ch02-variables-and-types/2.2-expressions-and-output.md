## Problem: Fill In the Missing Operators

The scoring calculator below is missing an operator on 2 lines (shown as a blank). Figure out which operator belongs on each blank so the printed output matches the comment above it, then predict the exact output before checking the solution.

```java
public class AutonScoreCalculator
{
    public static void main(String[] args)
    {
        // Total points scored across 3 auton legs: 4, 4, and 6
        System.out.println(4  4  6);

        // Average points per leg, as a whole number (int division — ok to truncate here)
        System.out.println(14  3);

        // Whether the robot completed a "clean" leg count: remainder when
        // dividing legs completed (5) by legs required (3)
        System.out.println(5  3);
    }
}
```

## Hints

- Line 1 needs two operators, not one — read the comment carefully.
- Line 2's comment explicitly says truncation is fine here — that's a clue about which types are involved, not which operator.
- "Remainder when dividing" is a direct description of one specific operator from this lesson.

## Solution

```java
public class AutonScoreCalculator
{
    public static void main(String[] args)
    {
        // Total points scored across 3 auton legs: 4, 4, and 6
        System.out.println(4 + 4 + 6); // 14

        // Average points per leg, as a whole number (int division — ok to truncate here)
        System.out.println(14 / 3); // 4 — truncated from 4.666..., which the comment says is fine

        // Whether the robot completed a "clean" leg count: remainder when
        // dividing legs completed (5) by legs required (3)
        System.out.println(5 % 3); // 2
    }
}
```

Output: `14`, `4`, `2`. The middle one is the one worth double-checking your instinct on — `14 / 3` is genuinely `4`, not `4.67` and not `5`, because both operands are `int` literals.
