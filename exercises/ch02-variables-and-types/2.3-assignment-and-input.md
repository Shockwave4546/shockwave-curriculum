## Problem: Swap the Primary and Backup Auto Paths

Your drive team wants to swap which autonomous path is "primary" and which is "backup" without losing either `String` value — but the code below has a bug: it overwrites `primaryPath` before saving it anywhere, so its original value is lost forever.

```java
public class AutoPathSwap
{
    public static void main(String[] args)
    {
        String primaryPath = "3-Piece-Left";
        String backupPath = "1-Piece-Safe";

        // BUG: this loses the original primaryPath value before backupPath can use it
        primaryPath = backupPath;
        backupPath = primaryPath;

        System.out.println("Primary: " + primaryPath);
        System.out.println("Backup: " + backupPath);
    }
}
```

Fix it so both variables end up with genuinely swapped values (`primaryPath` should end up `"1-Piece-Safe"`, `backupPath` should end up `"3-Piece-Left"`).

## Hints

- You cannot swap two variables in just 2 lines without losing one value along the way — you need somewhere to temporarily park one of them.
- Introduce a third variable to hold one value while you overwrite it.
- The order matters: save the value you're about to overwrite *before* you overwrite it, not after.

## Solution

```java
public class AutoPathSwap
{
    public static void main(String[] args)
    {
        String primaryPath = "3-Piece-Left";
        String backupPath = "1-Piece-Safe";

        String temp = primaryPath;  // 1. save primaryPath's original value before it's lost
        primaryPath = backupPath;   // 2. now safe to overwrite primaryPath
        backupPath = temp;          // 3. backupPath gets the saved original value

        System.out.println("Primary: " + primaryPath); // "1-Piece-Safe"
        System.out.println("Backup: " + backupPath);   // "3-Piece-Left"
    }
}
```

This 3-step pattern (save, overwrite, restore-from-save) is the standard swap idiom in any language without a built-in swap — it comes up anywhere you need to exchange two values: swapping drive-team path choices here, but just as easily swapping two array elements during a sort (see Ch.28).
