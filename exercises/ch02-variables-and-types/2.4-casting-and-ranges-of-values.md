## Multiple Choice

**Question:** A programmer casts a sensor voltage to get a whole-number LED brightness level: `int brightness = (int) 7.9;`. What value does `brightness` end up holding?

**Options:**

- A. 8
- B. 7
- C. 7.9
- D. This won't compile

**Answer:** B

**Why:** `(int)` always cuts off everything after the decimal point; it never rounds, no matter how close the decimal part is to the next whole number. `(int) 7.9` is `7`.

- A is wrong because this is a common assumption, but Java never rounds automatically during a cast — getting rounding requires the add-`0.5`-then-cast trick from this lesson, not a plain `(int)` cast.
- C is wrong because casting genuinely changes the type and drops the decimal; the value `7.9` does not survive.
- D is wrong because casting a literal directly is legal Java; this line compiles and runs without issue.

## Micro-Parsons

**Problem:** These lines, once correctly ordered, form a program that takes a precise arm angle reading and rounds it to the nearest whole degree for a driver-station display.

Reorder the fragments below into a working program:

- a. `        int roundedAngle = (int) (preciseAngle + 0.5);`
- b. `public class ArmDisplay`
- c. `    }`
- d. `}`
- e. `{`
- f. `    public static void main(String[] args)`
- g. `    {`
- h. `        double preciseAngle = 47.6;`
- i. `        System.out.println("Arm angle: " + roundedAngle + " degrees");`

**Answer:** b, e, f, g, h, a, i, c, d

```java
public class ArmDisplay
{
    public static void main(String[] args)
    {
        double preciseAngle = 47.6;
        int roundedAngle = (int) (preciseAngle + 0.5);

        System.out.println("Arm angle: " + roundedAngle + " degrees");
    }
}
```

**Why this order:** `preciseAngle` (`h`) has to be declared and given its value before it can be used inside any expression. `roundedAngle` (`a`) reads `preciseAngle`, so its line has to come after — and it uses the add-`0.5`-then-cast trick from the lesson: adding `0.5` first pushes `47.6` to `48.1`, and *then* `(int)` truncates that to `48`, the correctly rounded result (a plain `(int) preciseAngle` would have truncated straight to `47` instead). The `println` (`i`) comes last because it reads `roundedAngle`, which doesn't exist until the line before it runs. The class/`main` skeleton opens (`b`, `e`, `f`, `g`) around all of it, and the braces close in the reverse order they opened: `main`'s body first (`c`), then the class's body (`d`).
