# 2D Array Creation and Access — Exercises

## Multiple Choice

**Question:** The pit crew logs battery voltages in a 2D array — one row per battery, one column per check:

```java
double[][] batteryVoltages =
{
    {12.8, 12.6, 12.4}, // battery 1
    {12.9, 12.5, 12.1}, // battery 2
};
```

Which expression reads battery 2's third check (`12.1`)?

**Options:**

- A. `batteryVoltages[1][2]`
- B. `batteryVoltages[2][1]`
- C. `batteryVoltages[2][3]`
- D. `batteryVoltages[1, 2]`

**Answer:** A

**Why:** The first index is the row (the battery) and the second is the column (the check), and both start at `0`. Battery 2 is row `1`, and its third check is column `2`, so `batteryVoltages[1][2]` is `12.1`.

- B is wrong — it swaps row and column. Row `2` would be a third battery, which doesn't exist (valid rows are `0` and `1`), so this throws `ArrayIndexOutOfBoundsException`.
- C is wrong — it counts from 1 instead of 0. Row `2` and column `3` are both past the last valid index, so this also throws `ArrayIndexOutOfBoundsException`.
- D is wrong — Java doesn't use a comma between 2D indices. Each index gets its own pair of brackets, `[row][col]`, so this doesn't compile.

## Micro-Parsons

**Problem:** The pit's parts cabinet has 2 shelves with 3 bins each. These lines, once correctly ordered, form a complete program that creates an empty 2D array for the cabinet, stores 7 as the count for the bottom shelf's last bin, and prints that bin's count.

Reorder the fragments below into a working program:

- a. `        binCounts[1][2] = 7;`
- b. `    }`
- c. `public class PartsCabinet`
- d. `        System.out.println(binCounts[1][2]);`
- e. `    {`
- f. `        int[][] binCounts = new int[2][3];`
- g. `}`
- h. `    public static void main(String[] args)`
- i. `{`

**Answer:** c, i, h, e, f, a, d, b, g

```java
public class PartsCabinet
{
    public static void main(String[] args)
    {
        int[][] binCounts = new int[2][3];
        binCounts[1][2] = 7;
        System.out.println(binCounts[1][2]);
    }
}
```

**Why this order:** The class line (`c`) and its opening brace (`i`) come first, then `main`'s header (`h`) and its opening brace (`e`). Inside `main`, the array (`f`) has to be created before any element can be written. `new int[2][3]` gives 2 rows (shelves) and 3 columns (bins), all starting at `0`. The bottom shelf's last bin is row `1`, column `2`, so the assignment (`a`) stores `7` there. The print (`d`) has to come after that assignment, or it would print the default `0` instead of `7`. The braces close in the reverse order they opened: `main`'s (`b`) first, then the class's (`g`).
