# 2D Array Traversals: Nested Loops — Exercises

## Multiple Choice

**Question:** Robot inspection scores are stored with one row per inspector and one column per checklist item. A teammate writes this loop to print every score:

```java
int[][] inspectionScores = { {5, 4, 3}, {2, 5, 4} };
for (int row = 0; row < inspectionScores.length; row++)
{
    for (int col = 0; col < inspectionScores.length; col++)
    {
        System.out.println(inspectionScores[row][col]);
    }
}
```

What happens when it runs?

**Options:**

- A. It prints `5`, `4`, `2`, `5` — the last column is never printed
- B. It prints all 6 scores
- C. It throws an `ArrayIndexOutOfBoundsException`
- D. It prints only the first row: `5`, `4`, `3`

**Answer:** A

**Why:** The inner loop walks *columns*, so its bound should be `inspectionScores[0].length` (3). Instead it uses `inspectionScores.length`, the row count (2). So `col` only ever reaches `0` and `1`, and column `2` (the scores `3` and `4`) is silently skipped in both rows.

- B is wrong — that's what the loop would print with the correct inner bound, `inspectionScores[0].length`.
- C is wrong — here the wrong bound (2) is *smaller* than the real column count (3), so no index goes past the end. It skips data instead of crashing. (If the array had more rows than columns, the same bug would throw.)
- D is wrong — the outer loop's bound is correct, so both rows are visited. Each row is just missing its last column.

## Micro-Parsons

**Problem:** Given this class and main method, reorder the fragments below into the method body that creates a 2D array of arm-angle readings (one row per practice run, one column per checkpoint) and prints them in column-major order: every run's reading at checkpoint 0, then every run's reading at checkpoint 1, and so on.

```java
public class ArmCheckpoints
{
    public static void main(String[] args)
    {
        // fragments go here
    }
}
```

Reorder the fragments below to complete it:

- a. `            {`
- b. `        for (int col = 0; col < armAngles[0].length; col++)`
- c. `            }`
- d. `        int[][] armAngles = { {30, 60, 90}, {32, 58, 91} };`
- e. `                System.out.println(armAngles[row][col]);`
- f. `        {`
- g. `            for (int row = 0; row < armAngles.length; row++)`
- h. `        }`

**Answer:** d, b, f, g, a, e, c, h

```java
public class ArmCheckpoints
{
    public static void main(String[] args)
    {
        int[][] armAngles = { {30, 60, 90}, {32, 58, 91} };
        for (int col = 0; col < armAngles[0].length; col++)
        {
            for (int row = 0; row < armAngles.length; row++)
            {
                System.out.println(armAngles[row][col]);
            }
        }
    }
}
```

**Why this order:** The array (`d`) has to exist before either loop can read its lengths. Column-major means the *column* index changes in the outer loop, so the `col` loop (`b`) and its brace (`f`) come first. The `row` loop (`g`) and its brace (`a`) are nested inside it. Each loop's bound has to match what it walks: `armAngles[0].length` for columns, `armAngles.length` for rows. The print (`e`) sits inside both loops, so it runs once per element and prints `30`, `32`, `60`, `58`, `90`, `91`. The braces close in reverse of how they opened: the inner loop's (`c`) before the outer loop's (`h`). The class and `main` method are the given scaffold. Only the array declaration and the nested loop needed reordering.

## Coding

**Mode:** harness

**Problem:** Swerve telemetry is stored in an `int[][]` of current draw in amps, with one row per
module and one column per sample (the same layout as the lesson's `moduleCurrents`). A sample is a
**simultaneous spike** when **every** module reads at least `threshold` amps in that column. Write
`countSimultaneousSpikes`, which returns how many sample columns are simultaneous spikes. A reading
equal to `threshold` counts as at or above it. Every array has at least one row and one column.

Examples:

- `countSimultaneousSpikes(new int[][] { {40, 12, 41}, {42, 11, 45} }, 40)` returns `2` (columns `0` and `2`)
- `countSimultaneousSpikes(new int[][] { {10, 10}, {10, 10} }, 40)` returns `0`
- `countSimultaneousSpikes(new int[][] { {50}, {60}, {40} }, 40)` returns `1`

**Signature:** `public static int countSimultaneousSpikes(int[][] currents, int threshold)`

**Starter:**

```java
public class Solution
{
    public static int countSimultaneousSpikes(int[][] currents, int threshold)
    {
        // TODO: count the columns where every module is at or above threshold
    }
}
```

**Tests:**

| Visible | Arguments | Expected |
|---|---|---|
| yes | `new int[][] { {40, 12, 41}, {42, 11, 45} }, 40` | `2` |
| yes | `new int[][] { {10, 10}, {10, 10} }, 40` | `0` |
| yes | `new int[][] { {50}, {60}, {40} }, 40` | `1` |
| no | `new int[][] { {40, 40, 12}, {40, 13, 40}, {40, 40, 40} }, 40` | `1` |
| no | `new int[][] { {5, 50, 50, 5}, {50, 50, 5, 5} }, 50` | `1` |
| no | `new int[][] { {60, 60, 60}, {60, 60, 60} }, 60` | `3` |
| no | `new int[][] { {39, 90}, {90, 39}, {90, 90} }, 40` | `0` |

**Solution:**

```java
public class Solution
{
    public static int countSimultaneousSpikes(int[][] currents, int threshold)
    {
        int count = 0;
        for (int col = 0; col < currents[0].length; col++)
        {
            boolean allHigh = true;
            for (int row = 0; row < currents.length; row++)
            {
                if (currents[row][col] < threshold)
                {
                    allHigh = false;
                }
            }
            if (allHigh)
            {
                count++;
            }
        }
        return count;
    }
}
```

**Why:** The question is about one instant across every module, so this is a column-major
traversal: the outer loop walks the columns (bounded by `currents[0].length`) and the inner loop
walks the rows. Each column starts as "all high" and is ruled out by any module below the
threshold. A row-major loop can't answer this directly, because it finishes one module's samples
before it ever looks at the next module. A common mistake is counting a column when *any* module
spikes, which answers a different question.
