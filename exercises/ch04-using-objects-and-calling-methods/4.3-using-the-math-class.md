# Using the Math Class — Exercises

## Multiple Choice

**Question:** To get a random `int` representing an alliance station number from 1 to 3 (3 possible values), which expression is correct?

**Options:**

- A. `(int)(Math.random() * 3) + 1`
- B. `(int)(Math.random() * 3)`
- C. `(int)Math.random() * 3 + 1`
- D. `(int)(Math.random() * 4) + 1`

**Answer:** A

**Why:** The range size is `3` (three possible values: 1, 2, 3), so `Math.random()` is scaled by `3` first, then shifted up by the minimum value, `1`.

- B is wrong — it gives an `int` from `0` to `2`, never shifted up, so station `3` is never reachable and station `0` (invalid) is.
- C is wrong — the cast wraps `Math.random()` alone, truncating it to `0` *before* the multiplication happens, so the result is always `1`, no matter what `Math.random()` returns.
- D is wrong — the range size should match the count of possible values, which is `3`, not `4`; multiplying by `4` and shifting by `1` produces stations `1` through `4`, and there is no station `4`.

## Micro-Parsons

**Problem:** These lines, once correctly ordered, form a complete program that computes the straight-line distance from a robot's current position to a target position, given the `deltaX` and `deltaY` between them.

Reorder the fragments below into a working program:

- a. `        double deltaX = 6.0;`
- b. `    public static void main(String[] args)`
- c. `        double deltaY = 8.0;`
- d. `}`
- e. `    {`
- f. `        double distance = Math.sqrt(Math.pow(deltaX, 2) + Math.pow(deltaY, 2));`
- g. `public class TargetDistance`
- h. `    }`
- i. `{`
- j. `        System.out.println("Distance to target: " + distance);`

**Answer:** g, i, b, e, a, c, f, j, h, d

```java
public class TargetDistance
{
    public static void main(String[] args)
    {
        double deltaX = 6.0;
        double deltaY = 8.0;

        double distance = Math.sqrt(Math.pow(deltaX, 2) + Math.pow(deltaY, 2));
        System.out.println("Distance to target: " + distance);
    }
}
```

**Why this order:** The class line (`g`) and its opening brace (`i`) come first, then `main` (`b`) and its own opening brace (`e`). `deltaX` (`a`) and `deltaY` (`c`) must both be declared before either is used, and their declared order matches the order they're described in the problem. `distance` (`f`) depends on both — `Math.pow` squares each one, and `Math.sqrt` needs the sum of those squares, so this line has to come after both `deltaX` and `deltaY` exist but before it's printed. `distance` is printed (`j`) only once it's been computed, and finally `main`'s closing brace (`h`) and the class's closing brace (`d`) end the program.
