## Multiple Choice

**Question:** Which expression is logically equivalent to `!(isCalibrated || isHomed)`?

**Options:**

- A. `!isCalibrated || !isHomed`
- B. `!isCalibrated && !isHomed`
- C. `isCalibrated && isHomed`
- D. `!isCalibrated && isHomed`

**Answer:** B

**Why:** De Morgan's Law says negating an `||` flips it to `&&` and negates each side: `!(a || b)` is equivalent to `!a && !b`. Substituting in, `!(isCalibrated || isHomed)` becomes `!isCalibrated && !isHomed`.

- A is wrong because it keeps the `||` instead of flipping it to `&&` — that's the rule for negating an `&&`, not an `||`.
- C is wrong because it drops both negations entirely, which produces a completely different (non-equivalent) condition.
- D is wrong because it only negates one side (`isCalibrated`) while leaving `isHomed` unnegated — both sides have to flip.

## Micro-Parsons

**Problem:** A climb attempt should be flagged `INVALID` if it is **not** the case that (the climb time is under 15.0 seconds **or** the climb height reached at least 3.0 meters). These lines, once correctly ordered, apply De Morgan's Law to that negated condition, store the simplified result in a variable, and print `INVALID` when it's true.

Reorder the fragments below into a working program:

- a. `        boolean invalidClimb = (climbTime >= 15.0 && climbHeight < 3.0);`
- b. `{`
- c. `        if (invalidClimb)`
- d. `    public static void main(String[] args)`
- e. *(three lines, merged — this branch's only statement and its own braces, since nothing else could ever validly go between them)*
  ```java
          {
              System.out.println("INVALID");
          }
  ```
- f. `public class ClimbValidator`
- g. `        double climbHeight = 2.5;`
- h. `    {`
- i. `        double climbTime = 18.0;`
- j. `    }`
- k. `}`

**Answer:** f, b, d, h, i, g, a, c, e, j, k

```java
public class ClimbValidator
{
    public static void main(String[] args)
    {
        double climbTime = 18.0;
        double climbHeight = 2.5;
        boolean invalidClimb = (climbTime >= 15.0 && climbHeight < 3.0);

        if (invalidClimb)
        {
            System.out.println("INVALID");
        }
    }
}
```

**Why this order:** The class (`f`) and its opening brace (`b`) come first, followed by `main` (`d`) and its own opening brace (`h`). `climbTime` (`i`) and `climbHeight` (`g`) both have to be declared before the boolean expression can use them. That expression (`a`) already applies De Morgan's Law twice over: negating `!(climbTime < 15.0 || climbHeight >= 3.0)` flips the `||` to `&&`, flips `<` to `>=`, and flips `>=` to `<`. Once `invalidClimb` holds that result, the `if` (`c`) can check it directly, with its single-statement body and braces merged into one fragment (`e`), since nothing else could ever validly go inside them. `main`'s body then closes (`j`), followed by the class's own closing brace (`k`).
