# if Statements & For Loops — Exercises

## Multiple Choice

**Question:** A teammate writes this code intending to warn about low voltage:

```java
if (batteryVoltage < 11.0)
    System.out.println("LOW VOLTAGE");
    System.out.println("Check connections");
```

Suppose `batteryVoltage` is `12.5` (not low). What actually prints?

**Options:**

- A. Nothing prints
- B. Only `LOW VOLTAGE` prints
- C. Only `Check connections` prints
- D. Both `LOW VOLTAGE` and `Check connections` print

**Answer:** C

**Why:** Without curly braces, only the very next statement — `System.out.println("LOW VOLTAGE");` — is actually inside the `if`. The second `println` is a separate, unconditional statement that runs every time, no matter what the condition is. Since `batteryVoltage` is `12.5`, the `if`'s condition is false, so `LOW VOLTAGE` never prints — but `Check connections` always runs regardless, so it's the only line that prints.

- A is wrong because the second `println` isn't inside the `if` at all — it runs unconditionally, so it always prints something.
- B is wrong because it has the conditional line backwards — `LOW VOLTAGE` is the one gated by the condition, and that condition is false here.
- D is wrong because that's what would happen if the two lines were both wrapped in braces as one block — without braces, `Check connections` runs every single time, regardless of whether the condition is true or false.

## Micro-Parsons

**Problem:** Given this class and main method, reorder the fragments below into the method body that prints match numbers 1 through 5 in a loop, and additionally announces `ELIMINATION ROUND` right after printing the last match number (5).

Reorder the fragments below to complete it:

- a. `        }`
- b. `            if (match == 5)`
- c. `        for (int match = 1; match <= 5; match++)`
- d. `                System.out.println("ELIMINATION ROUND");`
- e. `        {`
- f. `            System.out.println("MATCH " + match);`
- g. `            {`
- h. `            }`

**Answer:** c, e, f, b, g, d, h, a

```java
public class MatchCountdown
{
    public static void main(String[] args)
    {
        for (int match = 1; match <= 5; match++)
        {
            System.out.println("MATCH " + match);
            if (match == 5)
            {
                System.out.println("ELIMINATION ROUND");
            }
        }
    }
}
```

**Why this order:** The `for` header (`c`) comes first, immediately followed by its opening brace (`e`) — the loop's body starts there. Every pass prints the match number first (`f`), unconditionally. Then the `if` (`b`) and its own opening brace (`g`) introduce the conditional check; the announcement (`d`) is the only thing inside that `if`. The braces close in reverse order of how they opened: the `if`'s body closes first (`h`), then the `for` loop's body closes last (`a`). The surrounding class and `main` method are the given scaffold; only the loop and its `if` needed reordering.
