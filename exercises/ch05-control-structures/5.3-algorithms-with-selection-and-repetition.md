# Algorithms with Selection and Repetition — Exercises

## Multiple Choice

**Question:** A team's climb routine is described as: "Extend the climber arm. While the arm is below its top hook position, keep extending it. Once it reaches the top, if the hook engages, stop the motor; otherwise, retract slightly and try again." Which of the three algorithm building blocks — sequence, selection, repetition — does this routine use?

**Options:**

- A. Repetition only
- B. Sequence and selection, but not repetition
- C. All three: sequence, selection, and repetition
- D. Selection only

**Answer:** C

**Why:** "Extend the climber arm" first is a sequential first step — it happens before anything else. "While the arm is below its top hook position, keep extending it" is repetition — a loop that keeps running until a condition changes. "If the hook engages... otherwise..." is selection — a true/false branch. All three building blocks appear together, which is typical of any real algorithm beyond a couple of lines.

- A is wrong because repetition is present, but so are sequence (the ordered steps) and selection (the if/otherwise branch).
- B is wrong because it misses repetition — the "while... keep extending" part is exactly a loop, repeating until a condition is met.
- D is wrong because selection is only one of the three blocks at work here — the ordered steps and the loop are both present too.

## Micro-Parsons

**Problem:** Given this class and main method, reorder the fragments below into the method body that prints `Cycle n` for each of 3 climb-practice cycles (1 to 3), and additionally prints `SUCCESSFUL CLIMB` whenever the cycle number is odd.

Reorder the fragments below to complete it:

- a. `            if (cycle % 2 != 0)`
- b. `        for (int cycle = 1; cycle <= 3; cycle++)`
- c. `        }`
- d. `            System.out.println("Cycle " + cycle);`
- e. `                System.out.println("SUCCESSFUL CLIMB");`
- f. `        {`
- g. `            {`
- h. `            }`

**Answer:** b, f, d, a, g, e, h, c

```java
public class ClimbCycles
{
    public static void main(String[] args)
    {
        for (int cycle = 1; cycle <= 3; cycle++)
        {
            System.out.println("Cycle " + cycle);
            if (cycle % 2 != 0)
            {
                System.out.println("SUCCESSFUL CLIMB");
            }
        }
    }
}
```

**Why this order:** The `for` header (`b`) starts the repetition, followed immediately by its opening brace (`f`). Each pass runs its steps in sequence: the cycle number prints first (`d`), unconditionally, every time. Then the `if` (`a`) and its own opening brace (`g`) add the selection — only cycles where the condition is true reach the announcement (`e`) inside. The braces close in reverse order: the `if`'s body first (`h`), then the loop's body last (`c`). The surrounding class and `main` method are the given scaffold; only the loop and its `if` needed reordering.
