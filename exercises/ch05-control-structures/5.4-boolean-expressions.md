## Multiple Choice

**Question:** A programmer wants to check whether `climberEncoderTicks` is odd, and writes `climberEncoderTicks % 2 == 1`. If `climberEncoderTicks` is `-3`, what does this expression evaluate to, and why?

**Options:**

- A. `true`, because `-3` is odd
- B. `false`, because in Java, `-3 % 2` evaluates to `-1`, not `1`
- C. `false`, because negative numbers can't be tested for oddness
- D. `true`, because Java treats negative remainders as positive

**Answer:** B

**Why:** In Java, `%` keeps the sign of the dividend, so `-3 % 2` evaluates to `-1`, not `1`. Comparing `-1 == 1` is `false` — so this expression wrongly reports `-3` as not odd, even though it is. This is exactly why `num % 2 != 0` is the safer general test for oddness: `-1 != 0` is `true` regardless of sign.

- A is wrong because although `-3` really is odd, this particular expression evaluates to `false` due to the sign of the remainder — it doesn't correctly detect it.
- C is wrong because negative numbers absolutely can be tested for oddness — just not with `== 1`, since their remainder comes out negative.
- D is wrong because Java does not flip the sign of a remainder to match the divisor — the remainder keeps the sign of the dividend (the number being divided).

## Micro-Parsons

**Problem:** These lines, once correctly ordered, form a complete program that declares the left and right drivetrain motor temperatures — left at 95°F, right at 88°F — then prints, in order: whether the left motor is running hotter than the right, whether the two temperatures are exactly equal, and whether the right motor's temperature is an even number.

Reorder the fragments below into a working program:

- a. `        System.out.println(leftTemp == rightTemp);`
- b. `    {`
- c. `        int rightTemp = 88;`
- d. `}`
- e. `public class MotorTemps`
- f. `        System.out.println(rightTemp % 2 == 0);`
- g. `    }`
- h. `        System.out.println(leftTemp > rightTemp);`
- i. `{`
- j. `    public static void main(String[] args)`
- k. `        int leftTemp = 95;`

**Answer:** e, i, j, b, k, c, h, a, f, g, d

```java
public class MotorTemps
{
    public static void main(String[] args)
    {
        int leftTemp = 95;
        int rightTemp = 88;
        System.out.println(leftTemp > rightTemp);
        System.out.println(leftTemp == rightTemp);
        System.out.println(rightTemp % 2 == 0);
    }
}
```

**Why this order:** The class line (`e`) and its opening brace (`i`) come first, followed by `main` (`j`) and its own opening brace (`b`). Both variables (`k`, `c`) have to be declared before any expression can use them, and the problem describes the left motor's reading before the right motor's, so `leftTemp` is declared first. After that, the three `println` calls just follow the order laid out in the problem statement: hotter-than check (`h`) first, equality check (`a`) second, and the even-number check on `rightTemp` (`f`) last. Then `main`'s body closes (`g`), followed by the class's own closing brace (`d`).
