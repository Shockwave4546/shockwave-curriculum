# Optional: HashMap (Dictionary) Data Structure — Exercises

## Multiple Choice

**Question:** Given:

```java
HashMap<String, String> subsystemStatus = new HashMap<String, String>();
subsystemStatus.put("Intake", "Ready");

String status = subsystemStatus.get("Climber");
```

What is the value of `status` after this code runs?

**Options:**

- A. `null`
- B. `""` (an empty string)
- C. Throws a `NullPointerException`
- D. `"Ready"`, since it's the only value in the map

**Answer:** A

**Why:** `get()` on a key that was never `put()` returns `null` rather than throwing an error — `"Climber"` was never added to the map, so there's no value to return.

- B is wrong — `null` and an empty string are different things; `get()` specifically returns `null`, not `""`.
- C is wrong — `get()` with a missing key does not throw; a `NullPointerException` risk only shows up later, if the `null` result is used without checking.
- D is wrong — `get()` looks up the value for the exact key given (`"Climber"`); it doesn't fall back to some other entry just because the map only has one so far.

## Micro-Parsons

**Problem:** These lines, once correctly ordered, form a complete program that stores one subsystem's status in a HashMap, then looks up and prints that same status.

Reorder the fragments below into a working program:

- a. `        System.out.println(subsystemStatus.get("Shooter"));`
- b. `public class SubsystemCheck`
- c. `    }`
- d. `{`
- e. `    public static void main(String[] args)`
- f. `}`
- g. `    {`
- h. `        HashMap<String, String> subsystemStatus = new HashMap<String, String>();`
- i. `        subsystemStatus.put("Shooter", "Spinning Up");`
- j. `import java.util.HashMap;`

**Answer:** j, b, d, e, g, h, i, a, c, f

```java
import java.util.HashMap;

public class SubsystemCheck
{
    public static void main(String[] args)
    {
        HashMap<String, String> subsystemStatus = new HashMap<String, String>();
        subsystemStatus.put("Shooter", "Spinning Up");
        System.out.println(subsystemStatus.get("Shooter"));
    }
}
```

**Why this order:** The `import` (`j`) precedes the class, and the usual class/main scaffolding (`b`, `d`, `e`, `g`) follows. The map must be created (`h`) before any pair can be stored in it (`i`), and a key must be `put()` before `get()` (`a`) can retrieve the value that was actually stored for it. The braces close in reverse: `main`'s body (`c`), then the class's body (`f`).
