# Array Creation and Access — Exercises

## Multiple Choice

**Question:** After this line runs, what is the value of `climberHookPositions[2]`?

```java
int[] climberHookPositions = new int[4];
```

**Options:**

- A. `0`
- B. `null`
- C. An undefined/garbage value
- D. This won't compile without an initializer list

**Answer:** A

**Why:** `new int[4]` creates a 4-element array, and every element starts at `int`'s default value, which is `0`. No initializer list was given, so all four slots equal `0` until something assigns them otherwise.

- B is wrong — `null` is the default for reference types (`String`, objects), not for a primitive like `int`.
- C is wrong — Java always sets array elements to a defined default; it never leaves them as garbage.
- D is wrong — `new type[size]` is a complete, valid way to create an array without an initializer list; both forms compile.

## Micro-Parsons

**Problem:** These lines, once correctly ordered, form a complete program that creates an array of 3 solenoid channel numbers using an initializer list, then prints the last channel's number using its index.

Reorder the fragments below into a working program:

- a. `        System.out.println(solenoidChannels[2]);`
- b. `public class PneumaticsConfig`
- c. `    }`
- d. `{`
- e. `    public static void main(String[] args)`
- f. `}`
- g. `    {`
- h. `        int[] solenoidChannels = {0, 1, 7};`

**Answer:** b, d, e, g, h, a, c, f

```java
public class PneumaticsConfig
{
    public static void main(String[] args)
    {
        int[] solenoidChannels = {0, 1, 7};
        System.out.println(solenoidChannels[2]);
    }
}
```

**Why this order:** The class (`b`) and its opening brace (`d`) come first, followed by `main` (`e`) and its own opening brace (`g`). The array (`h`) must be created before it can be indexed, so it comes before the `println` (`a`) — index `2` is the *last* valid index since indices start at 0, which is why it prints `7`. The braces close in reverse: `main`'s body first (`c`), then the class's body (`f`).

## Coding

**Mode:** harness

**Problem:** Write `makeCanIds`, which creates and returns a new `int` array with `count` elements holding the
consecutive CAN IDs `first`, `first + 1`, `first + 2`, and so on. If `count` is `0`, return an empty array.

Examples:

- `makeCanIds(4, 1)` returns `{1, 2, 3, 4}`
- `makeCanIds(3, 10)` returns `{10, 11, 12}`
- `makeCanIds(1, 7)` returns `{7}`

**Signature:** `public static int[] makeCanIds(int count, int first)`

**Starter:**

```java
public class Solution
{
    public static int[] makeCanIds(int count, int first)
    {
        // TODO: create the array, fill it, and return it
    }
}
```

**Tests:**

| Visible | Arguments | Expected |
|---|---|---|
| yes | `4, 1` | `new int[] {1, 2, 3, 4}` |
| yes | `3, 10` | `new int[] {10, 11, 12}` |
| yes | `1, 7` | `new int[] {7}` |
| no | `0, 5` | `new int[] {}` |
| no | `5, 0` | `new int[] {0, 1, 2, 3, 4}` |
| no | `2, 20` | `new int[] {20, 21}` |

**Solution:**

```java
public class Solution
{
    public static int[] makeCanIds(int count, int first)
    {
        int[] ids = new int[count];
        for (int i = 0; i < ids.length; i++)
        {
            ids[i] = first + i;
        }
        return ids;
    }
}
```

**Why:** `new int[count]` creates the array, with every element starting at `0`, and the loop then fills each
index from `0` to `length - 1`. Looping with `i <= ids.length` is the classic off-by-one and throws
`ArrayIndexOutOfBoundsException` on the last pass. When `count` is `0` the loop never runs, and the empty
array is returned as is.
