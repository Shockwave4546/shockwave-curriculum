# Why Java for FRC?

**Outline ref:** 1.1 — Why Java for FRC?
**Status:** existing — deck's original motivational slide, pulled verbatim. Intro only — no exercise, no CSA source; 1.2 is where the real lesson content starts.

Java is one of the most popular languages in the world, and the standard for most FRC teams.

- **Static Typing:** Catch errors at compile-time before they reach the robot.
- **Object-Oriented:** Perfect for modeling physical systems like motors and sensors.
- **Performance:** The JVM (Java Virtual Machine) is fast enough for real-time control loops.
- **Ecosystem:** Access to WPILib, thousands of libraries, and years of documentation.
